# 资产生成固定提示词

版本：1.0
更新日期：2026-07-18

这些提示词用于约束造型方向。尺寸、动作、预算和文件名仍以 `asset-production-spec.md` 为准。生成模型或图像时，把“公共前缀”与对应任务提示词一起提交。

## 公共前缀

```text
为硬科幻资源经营游戏 Tiny Cosmos 制作资产。场景是一台维护微型宇宙的科研设备，视觉来源是粒子加速器、真空腔体、射电阵列、低温仪器和轨道测量设备。主背景 #030608，设备主材质 #071419。观测与控制使用 #72E5F5，储能使用 #FFB84D，稳定与保护使用 #61E6A7，接触风险使用 #FF6577，反宇宙相位使用 #C594FF。结构连接必须合理，主轮廓清晰，发光区域小而有信息意义。禁止文字、Logo、水印、魔法阵、常规武器、飞船驾驶舱、眼睛、牙齿、触手团和对现有影视游戏设计的直接模仿。遵守给定尺寸、原点、正面方向、材质和动画名称，不自行增加动作。
```

## M001 观测核

```text
制作一个近似球形的微型宇宙观测核。中心是直径 0.62 m 的低温发光核心，外部有三条互相垂直、外径 2.2 m 的精密轨道环，环上均匀安装六个 0.16 m 观测节点。轨道环通过细小但可信的转轴与支架连接，缩小到 180 像素时仍能看清中心核心与三条轨道。主体为深黑青金属，只有核心、节点和窄测量刻度发出观测青光。轮廓接近科研仪器，避免飞船、武器和魔法阵联想。制作 idle、pulse、research、unlock、alert 五个动作，动作时长与帧数严格读取规格。固定种子 TC-FC-20260718-M001。
```

## M002 真空水蛭

```text
制作一种从微型宇宙视界背面形成的资源截流结构。总长 3.1 m，附着口位于原点，主体由五个不等长错位环节和一条可见的内部流动通道组成。它看起来像物理系统中的寄生谐振器，不像动物。附着口有机械相位锁定结构，主体从附着口向尾部先放大再收窄，左右存在 10%–15% 结构差异。外壳深灰黑，内部通道冷紫，附着口和危险纹局部红色。禁止眼睛、牙齿、骨头、昆虫足、黏液和无逻辑触手。制作 form、attach、siphon、overload、cutoff、observe、retreat 七个动作。固定种子 TC-FC-20260718-M002。
```

## M003 核心余像

```text
制作真空水蛭退去后留下的核心余像。它是一个直径约 0.86 m 的不完整双层球壳，内部悬浮三块互不接触的相位晶格，外壳有一条开放缺口。结构同时包含玩家观测青和反宇宙紫，颜色比例约 40:60，局部残留极少红光。轮廓需要表达“敌人带走的资源变成可利用记录”，避免宝箱、能量水晶、心脏和魔法球。制作 idle、condense、fuel、return、archive 五个动作。固定种子 TC-FC-20260718-M003。
```

## M004 通用生产单元

```text
制作可安装在资源轨道上的通用生产单元。尺寸 0.6×0.6×0.8 m，主体包括输入环、压缩腔和输出节点，资源沿本地 -Z 进入、沿 +Z 输出。轮廓紧凑，能够通过运行时颜色区分物质层。设备黑青金属占 85%，发光通道占 10% 以下。制作 idle、build、upgrade、starved 四个动作。固定种子 TC-FC-20260718-M004。
```

## M005 焦点透镜

```text
制作一个安装在轨道切线位置的观测焦点透镜。外径 0.9 m，由两层开口圆环、三片非玻璃测量叶片和一个小型校准节点组成。透镜法线朝核心，聚焦时三片叶片收拢并形成窄青色光轴。禁止普通相机镜头、望远镜筒和大面积透明玻璃。制作 idle、lock、release 三个动作。固定种子 TC-FC-20260718-M005。
```

## M006 保护信标

```text
制作一个表示资源保护底线的轨道信标。高度 0.7 m，底部是可夹持轨道的弧形锁扣，上部是双层六边框和一条绿色闭合回路。保护状态要表现为稳定边界，警告状态仅在回路缺口处出现琥珀脉冲。禁止盾牌、城墙、锁头等直接图标化轮廓。制作 idle、protect、warning 三个动作。固定种子 TC-FC-20260718-M006。
```

## M007 研究探针

```text
制作一台围绕观测核运行的研究探针。长度 0.8 m，由三点采样头、可折叠测量框和数据回传节点组成。采样时三点依次亮起，阈值动作让测量框展开并把一束青紫光送向核心。造型强调测量和比较，避免卫星太阳能板和航天器天线的常见轮廓。制作 idle、sample、threshold、unlock 四个动作。固定种子 TC-FC-20260718-M007。
```

## SVG 图标公共提示词

```text
输出纯 SVG。viewBox 0 0 64 64，安全区 6 像素，主线宽 2，最细 1.5，方形端点，无文字、数字、渐变、滤镜、嵌入位图和外链。使用 currentColor。图标在 16×16 像素下保留主要含义，在 64×64 下显示一层次级结构。所有图标使用同一几何网格和缺口宽度。
```

### I001 物质层级

- 夸克：一个中心点与三条短色荷矢量。
- 核子：三个互锁但不重叠的圆弧单元。
- 原子：中心核与一条不闭合测量轨道。
- 分子：三个原子节点和两条有方向的键。
- 细胞：双层边界、内部三个分区，不使用生物膜写实形态。
- 生命：两个互相供给的循环和一个状态节点。
- 文明：多节点网络穿过一个共同边界。

### I002 第一法则

- 急剧膨胀：三个从中心向外偏移的同心断环。
- 局部守恒：闭合六边形与两个对向流量箭头。
- 观测者效应：中央点、椭圆视界和一条测量刻度。

### I003 路线

- 推进：矢量越过不完整圆环。
- 维持：双环互相补充并形成闭合循环。
- 求证：三点采样与一条拟合曲线。
- 改写：两条镜像曲线在中心交换位置。

### I004 敌人处理

- 压倒：五段向同一核心推进的脉冲。
- 断供：被隔离线截断的流量通道。
- 观测：样本框、三个或四个计数点和焦点环。
- 同步：两条相差半周期的波形逐渐重合。

### I005 接触准备

- 库存缓冲：两层容量槽和一条可消耗外环。
- 脉冲蓄能：三个电容节点连接五段脉冲通道。
- 远距标定：焦点环、原子采样点和延长的预警刻度。

### I006 资源状态

- 循环：稳定闭环和单向流量标记。
- 短缺：断开的输入线与低位刻度。
- 过载：超过上限的柱和向外泄放线。

## VFX 公共提示词

```text
制作透明背景硬科幻状态效果，使用指定图集尺寸和帧数。效果中心稳定，边缘保留两像素透明扩展。避免烟雾爆炸、火焰、闪电、镜头光斑和高频噪声。发光通道细而明确，运动方向能够说明资源或相位流向。输出无损 PNG 图集和 WebP 候选文件，帧序从左到右、从上到下。
```

- V001：观测青脉冲从中心向六个节点传播，0.7 秒。
- V002：新轨道从低亮度测量点展开成完整圆环，2.2 秒。
- V003：低对比紫色相位偏移遮罩，可无缝循环，不包含亮点。
- V004：紫色流量从附着口向尾部移动，3 秒循环。
- V005：五段琥珀冲击依次穿过错位环节，0.8 秒。
- V006：绿色隔离平面从中心展开，边缘有少量琥珀警告，1.4 秒循环。
- V007：青色采样面扫描内部通道，留下三个或四个计数节点，3 秒循环。
- V008：紫色残留向一个不完整双层球壳凝结，2 秒。

## 终局灰盒提示词

P2 只生成低面灰盒和轮廓预览，统一深灰材质，不制作贴图：

- 越过视界：长轴结构穿过破裂环面，主方向清楚。
- 无尽花园：三个尺度的闭环互相供给，没有唯一中心。
- 最后观测者：大型测量框围绕空中心，采样点稀疏。
- 双生大坍缩：两个等权核心通过交叉通道互换位置。

每个灰盒控制在 5,000–12,000 三角面，只制作 `idle` 4 秒循环旋转预览。
