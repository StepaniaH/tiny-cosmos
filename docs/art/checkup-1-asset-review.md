# Tiny Cosmos 资产包第一次验收

验收日期：2026-07-18
来源：外部制作包 `tiny-cosmos-asset-pack`
目标版本：First Contact Vertical Slice / Build 0.6

## 结论

本批资产的工程完整性合格：独立执行 `scripts/validate_assets.py -- --root . --all` 得到 **31 passed / 0 failed**，目录、命名、GLB 动画名、SVG 规则、贴图尺寸和清单结构都通过自动检查。

自动检查通过不等于视觉验收通过。本轮只将能直接提升当前页面且不降低画面品质的资产接入正式运行时：

- **正式接入**：I001–I008 共 33 个 SVG 图标、T001 星尘背景纹理。
- **暂缓接入**：V001–V009、T002、T003。文件技术指标合格，但表现层级与现有 CSS/Canvas 效果接近；当前项目还没有精灵图播放器，贸然接入只会增加维护面。
- **退回重做**：M001–M007。动作和命名合格，造型、材质与轮廓语言仍处于程序化灰盒水平，不足以替换现有观测画布。
- **仅保留预研灰盒**：M101–M104，不进入当前第一次大流程。

项目中的 `assets/manifest.json` 已将通过项标记为 `enabled: true`，其余项继续使用现有回退表现，不会影响玩法。

## 模型退回意见

### M001 观测核

当前版本主要是球体、外环和方块的组合，几何关系平均，缺少一个能在截图中立刻被记住的主轮廓。外环均匀排布使它更像通用科幻 UI 装饰，而不是“处于宇宙外侧、靠观测维持描述”的装置。

下一版要求：

- 建立清晰的三层结构：不可直视的中心空缺、负责采样的非对称环组、把结果投影到宇宙中的输出骨架。
- 正面、侧面和 3/4 视角都必须能看出非对称结构；不要只依赖发光贴图区分。
- `idle` 要体现缓慢校准，`research` 要体现局部环组追踪不同频率，`unlock` 必须有一次明显的尺度重排。
- 材质至少拆成暗色结构体、冷色观测面、暖色警告面三组；粗糙度和边缘高光需要有层次。

### M002 真空水蛭

当前透视预览像几段断开的杆件和圆环，缺乏“从欠描述区长出来、只吸取被观察物质”的生命/机制感。即使骨骼和七段动画都存在，静帧轮廓仍无法承载第一次接触的威胁。

下一版要求：

- 轮廓采用“细长探针 + 可收缩口器 + 拖尾状缺失面”，避免普通机械虫或触手怪。
- 附着口必须是第一视觉焦点，并能和原子轨道形成清晰的吸取方向。
- 身体不应全部实体化：至少 30% 的体积用断层、负空间或稀疏点阵表达。
- `form → attach → siphon → retreat` 要能只看无声视频就理解事件顺序；`overload`、`cutoff`、`observe` 的结果轮廓必须不同。

### M003 核心余像

当前接近普通发光球，既不像真空水蛭留下的信息器官，也无法暗示它可能被归档、返还或当作燃料。

下一版要求：

- 使用残缺的“双壳结构”：外壳保持敌对体的吸取方向，内核显示本宇宙物质流向。
- 三种处置动作需要改变结构关系，不只改变颜色：燃料为坍缩、返还为反向展开、归档为冻结并分层扫描。
- 保留一种无法解释的微小周期动作，作为后续世界观伏笔。

### M004–M007 功能模型

生产单元、焦点透镜、保护信标、研究探针目前都是可用灰盒，但造型语言彼此过于接近，放入画布后会成为小型几何噪声。

下一版共同要求：

- 从远处只看剪影也能区分四类功能：生产是“循环”、聚焦是“收束”、保护是“包覆”、研究是“采样”。
- 每个模型只保留一个主要运动轴，避免所有部件同时旋转。
- 统一暗色结构材质，但为每类保留不同的活动面和运动节律。
- 交付 64×64 像素缩略图测试；缩小后若无法分辨，模型不通过。

## VFX 与纹理后续要求

V001–V009 的尺寸、透明通道和帧序通过，但视觉上多为同心圆、线条和简单发光，无法明显优于现有 CSS 动效。下一批不要求堆更多粒子，要求每个效果承担明确的信息作用：

| 效果组 | 必须表达的状态差异 |
| --- | --- |
| 手动脉冲 / 层级解锁 | 输入是向内采样；解锁是结构向外扩展，两者运动方向不能相同 |
| 警报 / 吸取 | 警报提示附着点；吸取显示物质从哪一层流失 |
| 过载 / 切断 / 观测 | 过载回灌、切断断面、观测驻波必须一眼可分 |
| 余像凝结 / 路线写入 | 前者是实体生成，后者是信息写入，不能都用扩散圆环 |

交付标准：

- 提供透明背景 WebP/PNG 图集以及真实逐帧录屏，不接受静帧拼接的视频占位。
- 循环首尾在差分图中无明显跳变；单次效果最后一帧能自然回落到 Canvas 状态。
- 同时提供正常、减少动态效果两档；减少动态效果不是简单降速，而是减少闪烁和大范围位移。
- T002 屏幕噪声需要给出 10%、25%、50% 三档强度预览；T003 反向侧纹理需要在接触事件实景合成图中验收。

优先级按实际接入价值排序：

每个模型下一次提交需要同时包含：四视图、64×64 剪影、材质球说明、动作表、真实逐帧视频、桌面/移动实景合成、GLB 与 `.blend` 源文件。模型面数通过脚本只是底线，视觉评审以轮廓、动作可读性和世界观一致性为准。

## 世界观视觉锚点

后续资产统一围绕以下设定，不使用泛用“蓝色全息科幻”作为主要风格：

- 观测者不在宇宙中建造机器，而是把“可被描述的关系”投影成操作界面。
- 青色表示已被稳定描述的关系；琥珀色表示正在付出代价或接近边界；红色只表示持续性危险。
- 结构越接近宇宙内部，越连续、实体；越接近反向侧，越断裂、非对称、包含负空间。
- 所有效果先说明物质或信息从哪里来到哪里去，再考虑装饰性发光。
