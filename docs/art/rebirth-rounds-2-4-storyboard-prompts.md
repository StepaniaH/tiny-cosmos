## 生成与交付参数

- 模型：GPT Image 2。
- 输入方向：横向、高质量；若只有 `1536×1024`，按 16:9 安全区构图。
- 最终文件：2560×1440、sRGB、WebP 质量 84–88。
- 单张目标体积：不高于 700 KB；31 张总量目标不高于 16 MB。
- 图片内禁止任何文字、数字、字母、Logo、水印、HUD 或漫画边框。
- 网页字幕位于左下；左侧 42%、底部 34% 保持低细节、低明度。
- 主要主体位于中心偏右；390px 移动端会偏右居中裁切，核心轮廓不能只存在于最右 18%。
- 路线分支图只表达路线世界状态，不把具体继承物名称画成可读标签。

## 第二轮专属提示词

每次提交使用“公共提示词 + 对应幕提示词”。

### R02-01 · 坍缩留下方向

```text
表现第一次定向大坍缩刚刚结束。绝大多数星系、轨道和物质链已经收束成近黑噪声，但中心偏右有一根极细、连续、非文字的方向性结构穿过坍缩：像一条被压缩到极限的可运行物理结论，由低亮白和少量琥珀、绿或青的中性分层构成。它不是光剑、道路或飞船航迹。坍缩中心已经熄灭，不画爆炸。重点是“完整宇宙消失，只有一个答案保持方向”。
```

### R02-02 · 带记忆醒来的 TC-07

```text
严格使用 TC-07 母版。观测核在黑暗中第二次启动，硬件数量和比例完全不变。三条轨道环上新增一道非常细、不可读的表面相位痕，跨越一个既有节点后进入中心球；它像材料经历坍缩后留下的可测应力，不像装饰刻纹。六个节点以不完全同步的青色狭缝光依次启动，其中一个节点保留极少量来自上轮真理的中性色残光。中近景，沉静，不做英雄觉醒。
```

### R02-03 · 继承物接回物质

```text
使用 TC-07 母版。在不改变三环六节点的前提下，一个独立的黑色陶瓷记忆模块通过两根可信低温连接件接入其中一个既有节点。模块由压缩的多层薄片、一个开放缺口和一条双向材料通道组成，不使用宝石、宝箱或徽章造型。模块一端让中心球中的第一批微粒更容易排列，另一端向视界背面投下一道很窄的债务影子，明确表达能力和约束同时接入。
```

### R02-04 · 有偏差的最初物质

```text
微观到介观尺度的物质形成场。夸克点、核子弧和最早原子轨迹仍从随机噪声建立，但中心偏右的一小片区域存在可重复的轻微拓扑偏差：同一类组合更容易沿一条曲线成立，附近另一个同样合理的组合则被挤向暗处。不要画箭头或概率图。让偏差像实验中真实可测但尚不能解释的初始条件，而不是巨大能量加成。
```

### R02-05 · 背面认出偏差（共享视界母版候选）

```text
构造正反两侧共享视界的系列母版候选。中心偏右是一层弯曲、半透明、厚度很小的观测视界，像巨型干涉仪测得的边界。正面有新生三层物质流和远处的 TC-07；背面没有镜像观测核，而是一组由五个错位谐振环、断续紫色流和缺口构成的无生命测量结构。它没有攻击，却已经把自己的环节旋转到与正面初始偏差对应的角度，表现“另一侧认出来了”。两侧只有因果对应，不是对称复制。
```

### R02-06-advance · 闭界格栅

```text
表现推进路线的第二轮反例。正面一条克制的琥珀开口方向即将穿过视界；背面提前展开一组巨大的闭界格栅，由多层无生命相位叶片和互锁测量弧组成，只在高吞吐方向合拢。格栅不是门、盾牌或武器，它像边界自发形成的方向过滤装置。旁边保留一个尺寸有限、尚未决定内容的载荷腔轮廓，表达远行权和容量取舍，而不是胜利点火。
```

### R02-06-sustain · 逆季候

```text
表现维持路线的第二轮反例。正面三个绿色资源闭环稳定运行，背面对应位置却形成缓慢扩大的紫色低压区；每当正面盈余流入缓冲膜，背面就出现一次稀薄的冬季波。两侧之间有清楚但不对称的交换通道，缓冲负担偏向其中一侧。不要画树林、花园或生物群落。用膜、流、储层和周期波表现“稳定成立，但冬天由谁承担”。
```

### R02-06-inquiry · 盲区证人

```text
表现求证路线的第二轮反例。正面 TC-07 的青色采样窗覆盖视界的一部分，采样区内背面结构完全静止且可重复；采样窗之外，一组紫色无生命谐振片正在改变位置，并在下一次聚焦前留下新的对照轨迹。用遮挡、采样边界和错位残影表达“行为只发生在未被观测的位置”。禁止眼睛、摄像头墙和数字界面。
```

### R02-06-rewrite · 失同步摆

```text
表现改写路线的第二轮反例。正面和背面各有一条相互穿过但不重合的相位曲线，沿公开节拍交替收缩与展开；背面额外加入一个由两个不等长臂构成的无生命相位摆，持续制造很小但累积的节拍误差。两侧偶尔进入紫青混合的宽容同步带，又很快分离。禁止钟表数字、魔法摆锤和时间旋涡。
```

### R02-07 · 经受反例的目标

```text
广角展示第二轮完整问题。前景偏右是 TC-07 与重新建立的七层物质阶梯；中景是共享视界；背面是一组已经针对正面惯用方法调整形状的结构。最远处同时出现两座尚未形成的文明节点网络轮廓，一座在正面、一座在背面。两者都不发出文字或人形信号。构图表达“这轮不是重复抵达文明，而是让答案在反例面前仍可被后来者讨论”。
```

## 第三轮专属提示词

### R03-01 · 两次终结的证词

```text
两次定向坍缩的残留轨迹在中心偏右叠合。第一条轨迹清楚、单向，第二条轨迹带有一次偏转、回流或采样修正；两者都已经失去原宇宙主体，却保留不同的曲率与材料痕。它们不是时间线图，而像真实引力与相位过程在新真空中留下的两组互不相同边界条件。两组证词既不互相覆盖，也不能完全拼成一个答案。
```

### R03-02 · 记忆不再是一条直线

```text
严格使用 TC-07 母版。两个独立记忆模块接入两个不同的既有节点，中央低温球内出现两种都稳定但无法完全对齐的测量节拍。三条轨道环保持母版结构，只在材料表面显现两轮细小相位痕。模块之间没有短路或战斗效果，而是通过一段开放的比较回路同时向中心提交结果。表现观测核第一次必须在真理、修正与债务之间维护张力。
```

### R03-03 · 结构之前的习惯

```text
表现环境记忆先于结构出现。前景是一片仍未形成完整分子的原子网络，环境中的低亮流线却已经勾出一种过去分子曾经采用的折叠路径；几个新原子沿这条路径更快抵达组合，另一些原子保留不同走向。路径像材料中的应力与催化地形，不像幽灵或预言。远处可见更高层结构的空位，但不要画成熟生命。
```

### R03-04 · 反继承物

```text
使用共享视界母版。正面继承模块连接 TC-07，背面则凝结出完全不同的无生命规则结构：由被截取流量形成的非对称壳、三个互不接触的相位晶格和一个面向自身物质链的输出缺口组成。它不是负面复制，也不附着攻击；它正在让背面的初始结构更容易存活。两件继承物隔着视界产生一次可见的规则干涉。
```

### R03-05-advance · 归航锚

```text
正面有一条封装良好的琥珀迁徙通道向外延伸，背面在远处形成归航锚：不是锁链或拖船，而是一组能让方向重新指向原边界的弯曲测量叶片。迁徙载荷继续向外，轨迹却开始获得一条可选择的返回曲率。画面同时保留被留在原处的低亮结构，表达“后来者可以远行，也开始要求远行者承担返航义务”。
```

### R03-05-sustain · 无主冬季

```text
四层资源环形成有记忆的绿色季候循环，但一片低温紫色冬季区拒绝固定在任何一侧：它沿共享视界缓慢迁移，经过哪一侧，哪一侧的缓冲膜就必须承担收缩。两侧都拥有可恢复结构，也都无法把冬季永久推给对方。不要出现自然雪景、树木或行星天气；使用低温材料、储层、膜和周期密度变化。
```

### R03-05-inquiry · 会避开档案的行为

```text
一个背面无生命结构在被青色采样窗完整记录后，下一代结构不再重复同一轮廓：旧样本仍清楚保存在左上远景，新结构在中心偏右通过改变一个相位连接、隐藏一段流量和增加不可观测缺口主动脱离分类。不要画生物进化树或数据库 UI。通过三代连续但逐步改形的谐振结构表现对象开始拒绝成为同一种证据。
```

### R03-05-rewrite · 异步祖谱

```text
正面结构按过去到未来形成三段清楚谱系，背面对应谱系的最后一段却先于中间原因出现；两组无生命结构通过共享视界在一个局部节点交叉，而不是整个时间反转。紫色与青色相位轨迹标出不同因果顺序，绿色只表示两个谱系都能存活。禁止 DNA 双螺旋、婴儿、祖先肖像、钟表和时间旅行门户。
```

### R03-06 · 另一侧的后来者

```text
视界背面第一次形成可辨认但非人形的后来者网络：多个尺度不同的节点通过可维护的紫色通信结构连接，每个节点保留反继承物的一小段材料语法。正面生命网络也在远处形成青绿回应。两边的信号沿同一边界到达，却采用不同节拍和连接顺序。表现“双方都有祖先与后来者”，不要固定镜像文明的身体、城市或统一徽记。
```

### R03-07 · 谁能继承谁

```text
广角展示第三轮七层物质链横跨共享视界。正面继承物与反继承物都连接到中间同一层资源，但通向四个不同保管位置：TC-07、正面文明网络、背面后来者网络和边界上的中性存储结构。没有任何一条通道已被高亮选定。画面核心是权限与责任的未决状态，不画王座、钥匙、投票箱或文字。
```

## 第四轮专属提示词

### R04-01 · 没有单一中心的坍缩

```text
表现第三次定向坍缩从正面与背面同时发生。画面中心偏右没有单一黑色引力井，而是两个不同曲率的收束区在共享边界上互相咬合；它们的失败位置形成一个稳定但带开放缺口的双层初始结构。少量前轮物质和相位痕被压入接口。不要画双黑洞碰撞、爆炸或太极图。
```

### R04-02 · 在边界内部醒来的 TC-07

```text
严格使用 TC-07 母版。观测核不再位于视界一侧，而是部分嵌入一层半透明弯曲测量边界：三环六节点全部完整，一半节点读取青色正面流，一半节点读取紫色背面流，中央球保持低亮中性白。边界穿过装置周围空间但不切开硬件。构图让 TC-07 看起来失去单方坐标原点，而不是被困或损坏。
```

### R04-03 · 真理成为材料

```text
三轮真理不以文字、奖章或图标出现，而分别成为同一物质链中的三种材料条件：一段结构更容易穿过开口边界，一段流量更容易形成可恢复闭环，一段相位可以被完整采样但生产略慢。三种条件同时帮助并限制七层阶梯，在一个位置互相冲突。具体路线颜色克制，结构关系比装饰更重要。
```

### R04-04 · 两件继承物运行在同一条链

```text
正面继承模块与背面反继承结构第一次接到同一段原子—分子物质通道。一个模块尝试加速、缓冲或采样，另一个模块按自身历史改变通道意义；中间物质没有被撕裂，而出现两组可同时读取的流向。使用可信连接、膜、晶格和相位接口表现规则竞争，禁止擂台、武器对峙和拟人手臂。
```

### R04-05 · 不止一个反侧声音

```text
背面文明信号分化成至少三种非人形、非徽章式结构语言：一组要求回送可能性的开放通道，一组要求共享证据的成对采样窗，一组拒绝被命名的低可见度空白节点。它们来自同一物质历史但没有统一中心。正面文明也有多个回应节点。不要设计具体派别制服、城市、人物、旗帜或可读符号，保持未来叙事开放。
```

### R04-06-advance · 两侧都有方向权

```text
共享边界上形成一个真实可穿越但没有所有者的开口。正面与背面各有一条方向不同、同等清楚的琥珀迁徙轨迹，两条轨迹争用有限的中性载荷腔；载荷内部只能看到生命种子、档案晶格和反侧证词结构的抽象轮廓，容量明显不足以全部容纳。表现门的两边都有人定义远方，不画舰队、战争或殖民旗帜。
```

### R04-06-sustain · 公开缓冲账本

```text
正面与背面共同形成覆盖视界的多层生态闭环，每个缓冲膜旁都有一条不含数字的可追踪材料回路，清楚显示波动由哪一侧吸收、何时可以退出。绿色稳定流和紫色相位流互相交换，但某一段仍承受更大形变，说明共同循环并不自动公平。不要画花园景观、和平握手或无限能源。
```

### R04-06-inquiry · 被观察者留下异议

```text
一座跨越两侧的最终测量站由 TC-07、正面文明和背面多个信号节点共同构成。每一组证据旁都有一个开放的异议轨迹：记录仍被保存，但对象可以标记不可观测区、不同解释或退出路径。使用采样窗、遮挡、对照材料和多源署名结构表达，不画巨大眼睛、法庭、签名文字或全知屏幕。
```

### R04-06-rewrite · 没有单方终点

```text
两条坍缩曲线在共享边界形成宽容同步区，正面与背面各自连接一个必须同时释放的无生命触发结构。两侧还各自封存一项当前优势：一段高吞吐被压入质量锚，一段稳定回流被暂时关闭。触发结构之间没有主从，任一侧单独动作都只会泄压而不会终结。禁止红蓝按钮、魔法仪式、时钟数字和“真结局”光环。
```

### R04-07 · 四份未来图

```text
在同一条共享视界上同时出现四种尚未选定的物理未来，不画成四张卡片：一处边界形成可穿越开口；一处形成跨两侧恢复闭环；一处形成分布式最终测量站；一处让两条坍缩曲线折回共同初始条件。四种结构彼此施加轻微形变，没有一项位于画面中心或亮度明显更高。让观众理解四者都能成立，也都必须修改其他未来。
```

### R04-08 · 共同署名的初始条件

```text
系列第一段跨轮叙事的汇合广角。TC-07 位于共享边界内部，正面七层物质链与背面不同方向的七层结构都连接到一枚尚未关闭的初始条件容器。双方文明网络各自送入一部分要保留的能力，也各自留下一个主动封存的空位。容器没有最终颜色或胜利光柱，保持开放、庄严、克制，表达下一次宇宙是否共同署名仍由玩家决定。
```

## 分批生产顺序

不要一次生成 31 张后再统一返工。按以下门槛推进：

1. **母版批**：R02-02、R02-05 各生成 4 个候选；锁定 TC-07 跨轮状态和共享视界母版。
2. **第二轮批**：完成 R02 全部 10 张；先做中文/英文 × 桌面/手机共 28 个页面样本。
3. **路线语法批**：R03-05 与 R04-06 的 8 张路线分支图，确认同一路线逐轮升级且四路线不互相混淆。
4. **第三轮通用批**：R03 其余 6 张。
5. **第四轮通用批**：R04 其余 7 张。
6. 每批通过后才导出 WebP 并写入生产日志，源 PNG 与最终 WebP 都记录 SHA-256。
