# 第三轮资产验收：页游优先

日期：2026-07-18

## 决定

本轮不再用端游级资产标准推动当前页游。资源分成三组：

- **接入网页**：T002 屏幕噪声、T003 反向侧噪声、20 个短事件音效。
- **继续打磨但暂不接入**：六层 96 秒音乐。工程问题已经修复，但双格式约增加 20 MB，且长时间听感尚未人工确认。
- **冻结至引擎重构**：M001–M104 三维模型、V001–V009 精灵图 VFX。当前 Canvas/CSS 表现更轻、更稳定，继续加入模型加载、骨骼动画和图集播放器不符合页游阶段的收益/成本比。

## 通过项

### T002 / T003

- T002 在 10% 强度下提供细微屏幕颗粒，不影响文字可读性。
- T003 只在反向侧预警和接触阶段叠加，静态 WebP 不引入逐帧 CPU/GPU 调度。
- 两个 WebP 合计约 256 KB，失败时现有背景和 Canvas 仍可正常运行。

### 短事件音效

- 20 个 MP3 合计小于 1 MB，48 kHz，按事件首次使用时加载。
- 不启用自动播放音乐，不在初始页面请求音频文件。
- 玩家拥有明确的“声音 · 开/关”按钮，偏好只保存在本地浏览器。
- 来源、制作方法和上游许可记录在 `assets/audio/NOTICE.md`，仓库不分发 SoundFont 本体。

## 性能边界

- 网页运行时不引入 Three.js、GLTF loader、骨骼动画器、VFX atlas player 或新的包管理依赖。
- 复杂资产文件继续保留在外部制作包，不复制进 Git 仓库。
- 将来迁移到 Godot 等端游引擎时，再以正式场景、灯光、材质、骨骼和性能预算统一复审三维资产。
