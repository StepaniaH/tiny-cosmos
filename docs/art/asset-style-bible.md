# Tiny Cosmos 资产视觉规范

版本：1.0
更新日期：2026-07-18

## 视觉目标

游戏画面是一台用于维护微型宇宙的科研设备。结构来源包括粒子加速器、真空腔体、射电阵列、低温仪器和轨道测量设备。表面允许磨损与制造痕迹，主体保持精密、克制和可读。

资产在深色背景中以轮廓、少量发光通道和状态颜色区分。发光承担信息功能：青色表示观测与控制，琥珀表示储能与准备，绿色表示稳定与保护，红色表示接触风险，紫色表示反宇宙与未知相位。

## 形状语言

### 玩家设备

- 基础形：圆环、同心轴、六边形框架、薄片透镜、测量刻度、断续轨道。
- 结构应看得出装配关系：支架、转轴、锁扣、传感节点、线缆通道具有明确连接点。
- 主要轮廓对称，局部校准组件允许 5%–10% 不对称。
- 边缘使用小倒角，避免完全锐利的 CG 切面。
- 装饰密度由中心向外下降，视觉注意力留给核心状态。

### 反宇宙结构

- 基础形：错位环节、非均匀重复、相位偏移、内部流动通道、局部镜像错误。
- 结构仍遵循可观察的物理连接，不能变成无逻辑触手团。
- 不使用眼睛、牙齿、骨骼、昆虫足、血肉、黏液等直接生物符号。
- 危险感来自流动方向、附着方式和相位异常。

### 路线与法则

- 推进：开口、矢量、穿越边界，方向由左下指向右上。
- 维持：闭环、冗余、对称交换，图形可首尾相接。
- 求证：采样点、测量框、拟合线、误差刻度。
- 改写：镜像交换、交叉映射、双重中心、相位重合。

## 禁止的造型捷径

- 大面积飞船装甲、驾驶舱玻璃、导弹、炮塔和常规武器轮廓。
- 魔法阵、卢恩文字、宗教符号、星座线和占卜图案。
- 霓虹都市、赛博朋克招牌、无功能的发光管线堆叠。
- 明显复刻《星际公民》《死亡空间》《EVE》《质量效应》《控制》或其他作品的可识别形状。
- 只有噪声、置换和高频细节，没有主次结构的模型。

## 材质词汇

### 金属框架

- Base Color：`#071419` 到 `#15242A`。
- Metallic：0.55–0.82。
- Roughness：0.24–0.46。
- Normal 强度保持轻微，实际游戏距离下不能出现闪烁。

### 陶瓷绝缘体

- Base Color：`#A7BBC0`，整体亮度压低到 35%–55%。
- Metallic：0。
- Roughness：0.48–0.68。
- 只用于节点、锁扣和透镜基座，占比不超过 15%。

### 发光通道

- 使用清晰的窄带，不覆盖整块表面。
- 常态 Emission Strength：1.2–2.2。
- 峰值：4.0，持续不超过 8 帧。
- 颜色由运行时状态确定，贴图中不烘焙强烈泛光。

### 半透明结构

- 最多两层可见透明表面。
- Alpha 0.18–0.55。
- 几何内部不能出现多层重叠导致的排序噪声。
- 如果透明排序不稳定，改用不透明深色壳体和发光细线表达内部结构。

## 细节尺度

- 一级轮廓：模型缩到 160–220 像素宽时仍能识别，占造型判断的 70%。
- 二级结构：支架、环节、开口和节点，占 25%。
- 三级细节：刻线、螺栓、磨损和微小接缝，占 5%。
- 小于最终屏幕 1.5 像素的几何细节不建模，合并到法线或直接删除。

## 动画节奏

- 待机动作缓慢、周期清楚，避免持续快速旋转。
- 玩家操作反馈在 0.7–1.4 秒内完成，峰值位于总时长 30%–45%。
- 解锁和重大决策可持续 1.8–2.4 秒。
- 警报动作使用一次明确异常和一段低幅循环，不使用全屏连续抖动。
- 循环动画首尾速度连续；机械部件停止时需要减速段。

## UI 图标

- SVG 使用单色 `currentColor`，页面负责上色。
- 线宽 2 像素，最细处不得低于 1.5 像素。
- 端点、拐角和缺口遵循同一网格。
- 禁止使用文字、字母、数字和渐变。
- 16×16 像素下保留主轮廓，64×64 像素下能够看到二级含义。

## VFX

- VFX 只增强状态变化，不遮住资源数字、按钮和任务文本。
- 单次效果在 0.5–2.4 秒内结束。
- 图集预乘 Alpha 关闭，边缘保留 2 像素透明扩展，减少采样黑边。
- 粒子方向与资源流一致：玩家资源向核心或高层流动，真空水蛭截流从附着口向尾部流动。
- 同屏粒子上限由运行时控制，图集本身避免高频细碎噪点。

## 预览灯光

- 世界背景：`#030608`，Strength 0.05。
- 主光：Area，6500 K，位于相机左上方 45°，能量以不过曝发光材质为准。
- 轮廓光：Area，相位紫，主光能量的 20%。
- 可选底部填充：观测青，主光能量的 8%。
- 预览禁止使用强景深、运动模糊和色差，便于检查真实轮廓。

## 四条结局预留

P2 只冻结轮廓方向：

- 越过视界：长轴结构穿过不完整圆环，主体向外打开。
- 无尽花园：多个闭环以不同尺度互相供给，中央没有唯一主核。
- 最后观测者：大型测量框和稀疏采样点围绕一个空中心。
- 双生大坍缩：两个等权核心互相镜像，在中线交换物质通道。

当前阶段只制作灰盒与轮廓预览。尺寸和动画在终局玩法验证后再冻结。
