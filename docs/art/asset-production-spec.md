适用版本：第一次接触竖切 Build 0.5（资产接口未变）

## 本机工具

- Blender：5.2.0 LTS，安装位置 `/Applications/Blender.app`。
- FFmpeg：已安装，可用于序列帧、透明 WebM 和预览视频转换。
- 页面当前使用 Canvas 与 CSS 占位，尚未接入三维运行库。

完成的资产先进入 `assets/` 并保持清单项 `enabled: false`。模型通过尺寸、动画和性能检查后，再安装渲染依赖并开启对应清单项。这样可以让美术生产和玩法开发并行，缺失模型不会阻止页面运行。

## 已冻结的公共约定

### 文件和接口

运行时只读取 [`assets/manifest.json`](../../assets/manifest.json)。代码通过 `id` 查询资产，通过 `animations` 映射播放动作。文件移动或动画重命名时必须先更新清单。

清单字段：

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `id` | 字符串 | 稳定资产标识，发布后不改名 |
| `type` | `model`、`icon_set`、`video` | 选择加载器 |
| `enabled` | 布尔值 | `false` 时使用程序化占位 |
| `source` | 字符串 | 相对项目根目录的文件或目录 |
| `fallback` | 字符串 | 现有 Canvas 或 CSS 占位标识 |
| `scale` | 三元素数组 | 运行时基础缩放，只用于模型 |
| `anchor` | 字符串 | 绑定页面场景中的固定锚点 |
| `animations` | 对象 | 游戏状态名到 GLB 动画名的映射 |

### 坐标、单位和原点

- Blender 场景单位：Metric，Unit Scale `1.0`，1 Blender Unit 等于 1 米。
- 制作坐标：Z 轴向上，模型正面朝 `-Y`。
- GLB 导出后：运行时 Y 轴向上，模型正面朝 `+Z`。
- 模型缩放在导出前应用，物体变换为 Location `0,0,0`、Rotation `0,0,0`、Scale `1,1,1`。
- 观测核原点位于几何中心。
- 真空水蛭原点位于附着口中心。主体沿本地 `-Z` 延伸，便于把附着口吸附到轨道锚点。
- 所有动作保持根节点原地。位移由页面场景控制，动画不写入持续 Root Motion。

### GLB 导出设置

- 格式：glTF Binary `.glb`。
- Include：Selected Objects。
- Transform：`+Y Up` 开启。
- Geometry：Apply Modifiers 开启；UV、Normals、Tangents 开启。
- Data：Custom Properties 关闭，除非清单增加对应读取规则。
- Animation：Animation 开启；NLA Strips 关闭；All Actions 开启；Always Sample Animations 开启；Sampling Rate `1`；Simplify `0`。
- 材质：Principled BSDF。透明材质使用 Alpha Blend，避免同一模型叠加超过两层透明表面。
- 纹理优先内嵌 GLB。单文件超过 12 MB 时再改为外置纹理，并补充清单字段。

## M001 观测核

交付路径：`assets/models/observation-core.glb`
清单 ID：`observation_core`
场景锚点：`stage_center`

### 外形与尺寸

- 包围盒：宽 `2.4 m`，高 `2.4 m`，深 `2.4 m`，允许误差 ±2%。
- 主体由一个直径 `0.62 m` 的发光核心、三条互相垂直的轨道环、六个观测节点组成。
- 轨道环外径 `2.2 m`，截面直径 `0.035 m`。
- 六个节点尺寸一致，最长边 `0.16 m`，均匀分布在三条轨道环上。
- 静态轮廓保持近似球形，避免尖锐舰船式结构。缩略到 180 像素宽时，核心和三条轨道仍需可辨认。

### 网格和材质预算

- 三角面：20,000–60,000，硬上限 70,000。
- 对象数量：最多 12 个，导出时允许合并静态环体。
- 材质：最多 2 套。
- `M_Core`: 深青黑金属，Base Color `#071419`，Metallic `0.72`，Roughness `0.28`。
- `M_Emission`: 发光青 `#72E5F5`，Emission Strength 由动画驱动，常态基准 `2.0`。
- 纹理：最多一套 2048×2048 的 Base Color、ORM、Normal；能够使用纯材质参数时不制作空白纹理。

### 动画

动画以 30 fps 制作，首尾循环帧只保留一次。

| 名称 | 时长 / 帧 | 循环 | 画面要求 | 游戏触发 |
| --- | --- | --- | --- | --- |
| `idle` | 4.0 秒 / 120 帧 | 是 | 三条轨道分别转动 18°、-24°、12°；核心亮度在 1.8–2.2 间缓慢变化 | 常态 |
| `pulse` | 0.7 秒 / 21 帧 | 否 | 核心在第 7 帧达到 1.18 倍，节点依次亮起；末帧回到待机姿态 | 点击中央光核 |
| `research` | 1.4 秒 / 42 帧 | 否 | 六节点向核心发送一次光序列，轨道不缩放 | 展开研究构成、研究点跨过阈值 |
| `unlock` | 2.2 秒 / 66 帧 | 否 | 新资源轨道由 0.15 倍展开到 1 倍，核心在第 36 帧达到最高亮度 | 揭示原子层 |
| `alert` | 1.5 秒 / 45 帧 | 是 | 一条轨道出现不完整逆转，两个节点改为琥珀色脉冲 | 敌人预警和接触中 |

动作结束后的姿态必须与 `idle` 第一帧一致。`pulse` 连续触发时允许从任意当前帧重新播放。

## M002 真空水蛭

交付路径：`assets/models/vacuum-leech.glb`
清单 ID：`vacuum_leech`
场景锚点：`contact_orbit`

### 外形与尺寸

- 静止包围盒：宽 `1.3 m`，高 `0.8 m`，长 `3.1 m`，允许误差 ±3%。
- 附着口外径 `0.34 m`，位于原点；轮廓由 5 个不等长环节和一条半透明内核构成。
- 环节从附着口到尾部逐渐放大，再在末端收窄。禁止明显的眼睛、牙齿和生物四肢。
- 左右轮廓有 10%–15% 的结构差异，主轴仍保持清晰，便于判断附着方向。
- 正常状态使用冷灰紫发光；危险信号只在局部变成红色，避免整模持续大面积红光。

### 网格和材质预算

- 三角面：40,000–80,000，硬上限 90,000。
- 骨骼：最多 36 根骨骼，每顶点最多 4 个权重。
- 材质：最多 3 套。
- `M_Shell`: Base Color `#10171D`，Metallic `0.55`，Roughness `0.38`。
- `M_Channel`: Base Color `#3B2D52`，Emission `#C594FF`，基准 Strength `1.4`。
- `M_Contact`: Base Color `#311018`，Emission `#FF6577`，基准 Strength `1.8`，仅供附着口和警报纹使用。
- 纹理：一套 2048×2048；透明内核允许独立 1024×1024 纹理。

### 动画

| 名称 | 时长 / 帧 | 循环 | 画面要求 | 游戏触发 |
| --- | --- | --- | --- | --- |
| `form` | 2.4 秒 / 72 帧 | 否 | 五个环节从尾部到附着口依次显形，末帧完整 | 预警出现 |
| `attach` | 1.2 秒 / 36 帧 | 否 | 附着口张开至 1.22 倍后闭合，根节点不位移 | 建立接触 |
| `siphon` | 3.0 秒 / 90 帧 | 是 | 内核亮点从附着口向尾部移动三次，外壳只有轻微呼吸 | 未选方案和持续截取 |
| `overload` | 0.8 秒 / 24 帧 | 否 | 冲击从附着口向尾部传播，末端出现一次失稳抖动 | 每次核子脉冲 |
| `cutoff` | 1.4 秒 / 42 帧 | 是 | 内核流动逐渐中断，附着口保持闭合 | 隔离开启 |
| `observe` | 3.0 秒 / 90 帧 | 是 | 内核流动清晰稳定，外壳出现可追踪的相位标记 | 观测方案进行中 |
| `retreat` | 2.0 秒 / 60 帧 | 否 | 附着口松开，环节从附着口向尾部依次熄灭 | 处理完成 |

`siphon`、`cutoff`、`observe` 的第一帧和末帧骨骼姿态一致。三个循环动作之间允许在 0.25 秒内交叉淡化。

## 批量制作时的固定输入

每个模型任务都附带以下参数，避免不同模型各自补全设定：

- 固定随机种子：使用 `asset-jobs.json` 中每个任务的 `seed`，例如 `TC-FC-20260718-M001`。
- 固定色板：青 `#72E5F5`、琥珀 `#FFB84D`、绿 `#61E6A7`、红 `#FF6577`、紫 `#C594FF`、背景 `#030608`。
- 固定镜头验收：正面、侧面、俯视、45° 透视各一张，正交焦距 70 mm，背景 `#030608`。
- 固定灯光验收：一盏 6500 K 主光、一盏紫色弱轮廓光，World Strength `0.05`。
- 允许变化：表面细纹、节点切角、10% 以内的局部比例微调。
- 冻结项目：包围盒、原点、正面方向、文件名、动画名、时长、材质数量、色板、三角面上限。

## 交付清单与验收

每个模型交付包含：

1. `.blend` 源文件，路径 `source-art/blender/<asset-id>.blend`，项目可暂不提交该目录。
