# 五轮主叙事：四次求生与一次认出

状态：canonical
更新日期：2026-07-26
用途：定义前四轮游玩、第五轮总结、碎片揭示、反派演化和不可避免的悲剧结尾。
上位文档：[产品愿景](../../product/vision.md)、[世界观圣经](../../game-design/world-bible.md)

> 本文包含完整剧透。玩家可见文本不得直接复制“作者真相”段落。

## 总体结构

游戏由四轮完整游玩和一轮较短总结构成。

前四轮不断提高玩家对成功的信心：

1. 我们也许只缺一个答案。
2. 我们也许只需修正旧答案。
3. 我们也许必须理解另一侧。
4. 我们也许只需双方合作。

第五轮证明这些尝试都曾发生，而且无论单方突破、循环共生、完整观测还是共同改写，都无法让有限宇宙永久存在。

## 不可违背的叙事规则

- 第一轮开始时，玩家不知道自己是谁。
- `TC-07` 可以作为界面、观测通道或调度功能出现，但不能被直接宣布为玩家本体。
- 反宇宙实际是另一个完整宇宙；“未选择可能性形成背面宇宙”是前期观察模型，不是作者真相。
- 两个宇宙都在避免终结，也都会把对方的求生行为体验成损失或入侵。
- 前四轮均以终结收束，不提供真正逃脱。
- 第四轮必须把希望推到最高：双方合作、条件成立、计算正确，然后仍然终结。
- 第五轮不再完整重复七层建设，主要玩法是重建、对照、验证和选择最后留下什么。
- 四条路线没有道德排名，也没有隐藏真结局。
- 玩家选择必须改变局部历史、牺牲、证词和最终表达；不能因为结局必然就把过程写成无意义假按钮。

## 三层对手

### 表层：反侧结构

真空水蛭、闭界格栅、逆季候、盲区证人、失同步摆和反继承物承担可操作冲突。它们有目标、速率、上限、预警与反制，不使用传统血条战斗。

### 中层：另一宇宙的求生意志

表层结构其实是另一宇宙维持资源、保存规律、传递历史或寻找出口的方式。它会学习玩家的成功方法，也会为了自己的延续做出残酷决定。

第三轮以前不完整证明它是宇宙；第四轮双方才能以相对平等的身份合作。

### 最终：终结

终结不是会说话的首领。它通过不断逼近的时间、熵压、可用状态减少和坍缩条件表达。各路线能够改变抵达终点的方式，不能删除终点。

## 固定碎片槽位

每轮使用五个叙事槽位，便于玩家跨轮对照：

1. **开场残留**：上轮留下什么，本轮哪里不对。
2. **法则偏差**：玩家第一次确定规律后出现一条矛盾证据。
3. **边界接触**：另一侧对本轮方法作出回应。
4. **生命或文明证词**：宇宙内部的后来者解释发生了什么。
5. **终结钩子**：本轮失败后提供进入下一轮的必要问题。

每轮建议三段可选碎片和两段必达总结。可选碎片错过后自动进入档案，不损失资源；所有身份与世界真相必须在必达内容中补齐。

## 第一轮：我们缺少一个答案

工作章名：**第一噪点**
主要情绪：探索、掌控、第一次紧张
玩家表面身份：未知的观察者或操作者
明确目标：建立第一座文明，在终结前完成一项文明提出的生存方案

### 开场

玩家只看见一条尚未稳定的观测通道和会回应操作的噪声。界面可以显示 `TC-07`，但不解释它是装置、节点、协议还是玩家。

前期目标依次回答：

- 现在做什么：让资源链运转。
- 为什么做：建立足够复杂的结构。
- 本轮终点：让文明提出并执行一项求生方案。

### 表层对手

真空水蛭先被理解为从未知边界截取资源的异常。玩家用压倒、断供或观测处理它，并留下第一组路线记录。

“被排除的可能性进入背面”可以由早期档案提出，但必须标为观察模型，例如：

> 模型 A：未采用的法则可能在不可见方向留下响应。现有样本不足以判断响应是否来自当前宇宙。

### 五个碎片

| 槽位 | 内容 | 玩家此时最多能推断 |
|---|---|---|
| 开场残留 | 终结报告的校验位早于本轮开机时间 | 这里不是绝对第一次启动 |
| 法则偏差 | 另一侧在选择落定前出现轻微预响应 | 对方可能预测方法 |
| 边界接触 | 截流结构也在保护某个不可见库存下限 | “敌人”并非只想破坏 |
| 文明证词 | 有生命梦见方向相反的七层结构 | 另一侧可能有组织 |
| 终结钩子 | 本轮报告与一份未知旧报告共享部分校验和 | 这个终点以前抵达过这里 |

### 失败

文明方案在局部成立：门打开、循环稳定、证据完成或双方短暂同步。玩家获得明确的成功反馈，然后更大尺度的终结仍然到来。

失败不能写成“你选错了”。结算只指出方案保存了什么、牺牲了什么，以及为什么这仍不足以取消终结。

## 第二轮：答案遭遇反例

工作章名：**回声有了方向**
主要情绪：熟悉、偏差、被认出
明确目标：让上轮答案通过针对性反例，决定重复、修正或保留争议

### 可保留的现有骨架

当前第二轮的 12 节点、四条路线反例、继承校准、文明证词和真理裁定均可继续使用。叙事解释需要从“背面由我们创造”逐步改成“另一来源记得它如何被我们的答案伤害”。

### 五个碎片

| 槽位 | 内容 | 新认识 |
|---|---|---|
| 开场残留 | 一条上轮规律穿过终结，但附带未支付代价 | 继承不是纯奖励 |
| 法则偏差 | 尚未出现生命，本轮研究通道却读出文明用语 | 记忆来源不只在当前时间 |
| 边界接触 | 对方使用上轮成功方法的反向模型 | 它记得的不是资源，而是行为 |
| 文明证词 | 另一侧把玩家的焦点或过载称作自己的截流现象 | 双方描述可能对称 |
| 终结钩子 | 两侧终结报告出现相同校验和与相反资源方向 | 另一侧也可能经历了一轮宇宙 |

### 失败

无论重复、修正或保留争议，第二轮文明都能形成更好的局部结论。随后终结再次发生。

下一轮钩子不是“再强化一次”，而是：

> 如果另一侧也能把失败带过终结，谁有资格把自己的残留称为历史？

## 第三轮：两侧都有祖先

工作章名：**两个宇宙都开始继承**
主要情绪：历史重叠、身份不稳、第一次对等
明确目标：处理双方继承规则的冲突，决定历史由谁保存、公开和反驳

### 新机制叙事

另一侧带来反继承物。它不是玩家装备的负面复制，而是对方把前两轮损失压缩成的生存规则。

真空水蛭等旧敌人开始被重新解释：

- 真空水蛭：另一侧获取低熵资源的边界通道。
- 反相晶簇：另一侧稳定未完成结构的支架。
- 静默合唱体：另一侧寻找共同节拍的探针。
- 镜像胚种：另一侧让谱系跨越终结的连续性载体。

这些是第三轮得到的较好模型，仍不要求玩家立即知道自己也是宇宙。

### 五个碎片

| 槽位 | 内容 | 新认识 |
|---|---|---|
| 开场残留 | 对方带来有来源、有约束的反继承物 | 另一侧拥有自己的跨轮历史 |
| 法则偏差 | 两侧档案对同一事件给出相反主客体 | “入侵者”取决于观察方向 |
| 边界接触 | 对方后来者首次使用“我们”并引用祖先 | 另一侧有连续主体 |
| 文明证词 | 双方文明都请求停止由单一观察者命名历史 | 解释权本身是冲突 |
| 终结钩子 | 双方签名都把各自的观察节点列为内部结构 | 也许从来没有外部观察者 |

### 失败

玩家可以建立共享档案、隔离继承、交换规则或保持异议并存。这些决定改变第四轮的合作条件。

终结仍会发生。原因不再归咎于另一侧，而是双方任何一方都无法独占足够条件永久维持自身。

## 第四轮：所有条件都已满足

工作章名：**没有外侧**
主要情绪：宏大、紧张、希望达到最高点后断裂
明确目标：让两个宇宙共同执行一项终末方案，公开计算并消除过去的单方盲区

### 开场

双方已经承认彼此拥有历史。共享边界可以是谈判桌、证据仓、资源交换层或共同触发器，但不是预设和平。

第四轮第一次让两侧同时公开：

- 需要保留的结构。
- 愿意封存的优势。
- 可承受的损失。
- 失败时由谁泄压。
- 终结预测与误差。

### 四种方案

- **越过视界**：双方共同决定载荷与方向权。
- **无尽花园**：公开缓冲账本、退出权和短缺承担者。
- **最后观测者**：证据允许多方署名、异议与不可观测区。
- **双生大坍缩**：双方共同选择同步窗口和封存能力。

四种方案都必须有独特操作，但最终都进入同一事实：方案达成不等于无限持续。

### 五个碎片

| 槽位 | 内容 | 新认识 |
|---|---|---|
| 开场残留 | 边界从两侧同时建立，不再有绝对正面 | “反宇宙”只是相对称呼 |
| 法则偏差 | 每次移动 TC-07 焦点，当前宇宙总状态都发生对应变化 | 观测节点可能属于被观测对象 |
| 边界接触 | 两侧交换完整终结模型，预测一致 | 对方没有隐藏万能答案 |
| 文明证词 | 两侧共同宣布条件满足，拒绝把失败归咎于对方 | 合作不是骗局 |
| 终结钩子 | 所有成功指标为绿后仍发生终结；系统找不到任何宇宙外坐标 | 第五档案开放：观察者是谁 |

### 失败

这是全篇最重要的失败：

- 玩家计算正确。
- 双方没有背叛。
- 方案按规则成功。
- 此前选择确实降低了损失或保住了更多历史。
- 宇宙仍然结束。

不要在最后一秒增加反派袭击、隐藏资源不足或操作失误。那会把哲学悲剧降格成一次普通失败。

## 第五轮：观测者是谁

工作章名：**最后一份档案**
主要情绪：清晰、否认、证据耗尽、绝望
形式：15–25 分钟交互式总结，而非完整资源重建
明确目标：拼合四轮档案，确定观察来源，并选择最终留下的记录

### 玩法结构

1. 四轮档案以不可读轮廓出现。
2. 玩家通过配对校验和、对齐两侧时间、重放关键决策和验证因果，逐翼解码。
3. 每解码一翼，显示本轮方法在更早历史中的若干等价变体。
4. 中段揭示 `TC-07` 是当前宇宙内部的自观测与调度功能，不是站在宇宙外的主人。
5. 随后揭示玩家一直是当前宇宙本身；操作界面只是它能够理解自己的方式。
6. 反宇宙是另一个同样把自身体验成“我”的宇宙。
7. 最后展示四类方法都曾多次成立、失败、修正和再现。
8. 玩家选择最后留下哪种记录，随后两侧共同终结。

### 最终选择

最终选择不再伪装成生存按钮。可以让玩家决定：

- 留下一份关于远行与舍弃的记录。
- 留下一份关于照料与负担的记录。
- 留下一份关于证据与观看权的记录。
- 留下一份允许矛盾同时存在的记录。

选择读取前四轮真实行为，改变最后通信、档案排序和终幕意象，不改变终结。

### 最终表达

终幕语言应简单，避免继续堆叠设定名词。可使用的基调：

> 所有方法都曾奏效。没有一种能让时间停下。

> 你没有输给另一个宇宙。它也没有赢。

> 它们都做对了。宇宙还是结束了。

正式版本只需选择少量句子，并根据玩家路线留下不同前文。

## 碎片化叙事的交互规则

碎片不能只是等待时弹出的小说段落。首批可复用四种轻交互：

- **信号配对**：在两到三条短句中找出共享校验位。
- **来源判断**：判断记录来自当前宇宙、另一侧或无法确认；允许保留争议。
- **观测带宽分配**：短时选择看清资源、行为或证词中的一项。
- **预测验证**：在公开范围内预测下一次反侧动作，结果无惩罚地进入证据。

共同约束：

- 不要求持续盯屏。
- 错过后自动归档。
- 不打断稳态或资源计时。
- 不提供数量级收益。
- 每段只揭示一个新事实。
- 同一轮的关键真相必须能在结算重读。

## 如何保护选择的意义

结局必然不等于过程相同。

系统应永久记录：

- 哪些文明、谱系和资源被保护。
- 谁承担了缓冲、损失与不可观测区。
- 玩家是否公开证据、允许异议或压倒对方。
- 另一宇宙如何评价这段关系。
- 每轮留下的句子、债务和未解问题。

第五轮展示的是“同类策略曾反复出现”，不是宣称玩家当前每次按钮点击都被预写。玩家仍然是这一次历史的作者，只不是终结的例外。

## 与当前实现的关系

- 第一轮现有资源、接触和文明流程属于 implemented 基线，需要后续调整身份与反宇宙解释。
- 第二轮 12 节点和路线反例属于 implemented 基线，可以保留其玩法骨架。
- 已完成的第一、第二轮无文字图片可以通过新字幕继续使用。
- 旧第三、第四轮分镜与剧情属于 historical/proposal 输入；继续生产前必须重新映射到本文。
- 本文没有宣称第三、第四、第五轮已经进入代码。

## 叙事验收

- 第一轮结束前，玩家不能被明确告知“你是宇宙”。
- 第二轮玩家能理解对方记得行为，而不只是获得数值强化。
- 第三轮玩家能复述“另一侧也有历史和后来者”。
- 第四轮失败不能被解释为背叛、算错或隐藏条件。
- 第五轮身份揭示能由前四轮证据回溯，而不是突然宣布。
- 知道结局必然后，玩家仍能指出至少三项由自己选择改变的局部结果。
- 任意路线都不会被标成较正确、真结局或逃生答案。
