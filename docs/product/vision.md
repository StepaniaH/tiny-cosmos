# Tiny Cosmos 产品愿景

状态：canonical
更新日期：2026-07-26
用途：定义作品最终体验、玩家承诺与设计取舍的最高层基线。
上位文档：无

## 一句话愿景

玩家在四次看似越来越接近成功的宇宙经营中探索、计算和选择；第五轮将碎片合并，揭示玩家就是宇宙本身，所谓反宇宙只是另一个同样求生的宇宙，而所有努力都只能改变过程与被留下的记录，不能取消终结。

## 最终要表达什么

Tiny Cosmos 讨论的不是“努力毫无价值”，而是两个同时成立的事实：

1. 一个宇宙相对于漫长时间和必然终结极其渺小。
2. 无法永存，不代表局部选择、关系、牺牲和记忆没有差别。

悲剧来自玩家确实学会了系统、作出了更好的决定，也确实让某些生命活得更久、让某些历史被看见；但这些成就仍然无法把有限变成无限。

## 玩家体验曲线

整段体验遵循：

> 探索 → 建立目标 → 计算与决策 → 似乎可行 → 失败 → 带着证据重来 → 叙事逐渐清晰 → 共同求生 → 仍然终结 → 认出自己

前四轮是完整游玩轮次，第五轮是较短的交互式总结：

- 第一轮建立好奇、控制感和第一次失败。
- 第二轮让旧答案遭遇有针对性的反例。
- 第三轮证明另一侧也有历史、继承和后来者。
- 第四轮让双方合作并把“似乎可以”推到最高点，再让终结发生。
- 第五轮把四轮档案拼合，揭示身份、对称处境和无数次重复。

详细结构见 [五轮主叙事](../design/narrative/five-loop-arc.md)。

## 玩家承诺

### 随时知道自己在做什么

前期目标感必须早于术语和长篇世界观：

- 首屏显示本轮长期目标、当前目标和下一里程碑。
- 每个任务用一句直接动作说明条件，用可选说明解释原因。
- 第一处有后果的选择尽早出现；长资源等待不能成为唯一推进方式。
- 失败必须能说清原因、损失上限和恢复路径。

### 等待时可以离开，也可以主动思考

放置负责时间感和资源自然生长，不承担主要乐趣。等待期采用三层结构：

1. **被动层**：生产、研究和计时继续，离开不会受罚。
2. **可选主动层**：低频观测事件、信号配对、短期调度或证据判断；错过只自动归档。
3. **长期建设层**：少量会改变事件、证据和文明回应的机构，不做通用城市建设。

主动玩法奖励信息、路线证据和调度机会，不把玩家变成每隔几秒清一次提示的值班员。

### 决策改变过程，而不是制造假胜利

推进、维持、求证、改写继续代表四类真实方法。它们应改变：

- 资源压力和操作顺序。
- 反侧回应和文明立场。
- 谁被保护、谁承担缓冲、哪些证据被公开。
- 下一轮的初始偏差、能力和约束。
- 第五轮如何拼合历史，以及最后留下的记录。

它们不改变终结是否发生。最终不能突然出现隐藏真结局、付费逃生或因为集齐收藏而取消主题。

### 中文首先要自然、清楚

哲学性来自信息关系与最终发现，不来自每句话都写得抽象。

- 操作层使用日常、具体、数字优先的中文。
- 诗意主要留给碎片、文明通信和终局。
- 同一段不连续堆叠“结构、形成、确定、记录、公开、可陈述”等抽象名词。
- 一个界面只保留一条主要目标，不靠缩小字号容纳重复解释。
- 关键后果、成本、倒计时和失败恢复永远不能藏在氛围文案里。

### UI 突出重点

界面首先服务当前决策，其次服务观察和档案。

可以把主体验拆成两个互通视图：

- **操作页**：资源链、焦点、保护、任务、接触和当前选择。
- **放置/观测页**：宇宙画布、长期建设、碎片、离线回归和档案线索。

是否最终拆页由可用性验证决定，但信息层级必须先成立：主要目标和重要数值大于装饰信号，正文无需靠近屏幕阅读。

### 成长提供新规则，不只提供倍率

天赋点、继承物和跨轮解锁用于丰富决策：

- 优先解锁新处理方法、规则槽、事件分支和观察能力。
- 每次强化同时说明适用场景和约束。
- 固定倍率设上限，避免第五轮只剩数值膨胀。
- 不允许天赋树泄露第五轮身份真相。

## 反派与冲突承诺

反宇宙不是纯恶阵营。

- 前期玩家把截流结构视作敌人。
- 中期发现对方会记忆、预测并留下证词。
- 后期确认对方是另一个完整宇宙的求生行为。
- 真正不可战胜的对手是有限宇宙的终结，而不是一名等待被击杀的首领。

对方可以做出残酷决定，也可以在第四轮合作；同情它不等于取消资源冲突。

## 内容与商业边界

当前优先验证的是一款可保存、可重复试玩、以叙事和系统决策为核心的独立作品。

暂不把项目扩张为：

- 高频点击或注意力惩罚型放置游戏。
- 完整城市建设、实时战斗或多人竞争。
- 以装备稀有度和无限倍率为核心的刷取游戏。
- 通过大量长文本替代可操作内容的视觉小说。
- 用“其实有一个完美结局”撤销悲剧主题的解谜游戏。

## 近期判断标准

在继续扩大第三、第四轮内容前，至少验证：

1. 新玩家在两分钟内能复述本轮目标。
2. 玩家在等待阶段能找到一项可选但不强制的事情。
3. 默认字号下，关键目标、选择后果和接触数据无需放大页面。
4. 玩家能用自己的话区分四类方法，而不是只记住颜色。
5. 第二轮结束后，玩家理解“旧方法被针对”，但尚未提前猜中最终身份。
6. 玩家相信选择改变了历史，即使已经知道终结无法避免。
