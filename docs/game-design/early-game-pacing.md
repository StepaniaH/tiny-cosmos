# 第一次接触前期节奏

状态：implemented
更新日期：2026-07-26
用途：记录当前第一轮前期节奏、主动观测与天赋的已实现基线。
上位文档：[产品愿景](../product/vision.md)

## 时间目标

- 自动最优操作：9–12 分钟。
- 熟悉系统的普通玩家：15–20 分钟。
- 第一次进入、阅读全部说明并比较选择：18–25 分钟。
- 单个教学浮层连续停留：通常不超过 90 秒。
- 单段纯等待：不超过 40 秒；更长阶段必须提供可以缩短时间或修复进度的操作。

当前冒烟测试遍历 27 个法则、准备与处理交叉组合；观测组合会先故意承受截取，以覆盖受控预算边界。2026-07-26 的完整矩阵耗时范围为 9 分 31 秒至 11 分 42 秒。

自动流程持续执行最优合成、购买和焦点操作，没有阅读时间。它用于检查最低时长和逻辑闭环，不代表正常试玩速度。

## 已采用的减速方式

### 第一项长期目标始终可见

首屏目标栏同时显示：

- 本轮长期目标。
- 当前需要完成的动作与实时进度。
- 下一项系统解锁。
- 等待时可以进行的可选操作。

任务标题优先使用“购买第 2 个夸克单元”“稳定三层物质 60 秒”这类直接中文；原因与世界观退到次级说明。

### 系统按理解顺序开放

首屏只显示资源、画布、当前目标与场景引导，不显示空的“成长 / 干预”入口：

1. 玩家先完成点击与自动生产。
2. 进入核子合成后开放主动观测，并保留一块首次说明，直到玩家真正使用一次。
3. 完成研究构成教学后才获得第一个天赋点；此时“成长”工作区首次出现。
4. 第一法则到来时，“成长”更名为“干预”，并开放决策队列与路线信号。
5. 接触读数出现后，接触面板才加入干预工作区。

这样主动观测先承担等待期操作，天赋再承担中期构筑，决策最后引入路线含义。四项天赋每轮最多两级：

- 深度聚焦：强化焦点层生产。
- 流量整序：降低全局代谢需求。
- 并行推演：提高研究增长。
- 回声蓄能：缩短主动观测充能。

主动观测最多保存 3 次，基础每 45 秒恢复 1 次；系统解锁后，在线与离线都会充能：

- 稳态校准：强化当前净流量最低、且确实有产出的层。
- 聚焦脉冲：短时放大当前焦点；没有有效焦点时选择最高的有产出层。
- 解码回声：立即获得约 20 秒的当前研究增长，最低 3 RP。

持续协议互斥，解码可以在持续协议期间使用。它们不写入路线倾向，不要求玩家定时清理，也不会因离线而错过。

### 发现不再拉长页面

偶发发现触发时，画布上半部出现醒目的“新发现”信标，标题和待处理数量始终在当前一屏可见。玩家点击后才打开悬浮阅读层：

- 生产、稳态计时与当前任务不会暂停。
- 普通碎片可以“收起并保留”，之后从观测档案重读。
- 带选择的现象必须先回应，且不会离线过期。
- 多条发现按触发顺序排队，处理当前一条后显示下一条。

### 开局没有预设焦点

初始焦点为空，夸克不会在教学前获得 1.8 倍加成。玩家完成核子生产单元后第一次建立焦点，焦点的收益可以直接与此前速度比较。

### 首次生产单元成本独立

竖切使用独立生产单元基础成本：

- 夸克 14。
- 核子 8。
- 原子 5。

长期模式的数值保持不变。第一次购买需要短期积累，之后仍能看到生产投入带来的加速。

### 研究由经营加速

原子研究成本提高到 45 RP，竖切研究倍率从 4 降到 2.6。玩家可以通过保存更多夸克、核子和增加生产单元提高平方根研究贡献。研究阶段保留可操作的加速空间。

### 连续稳定任务

两个稳定任务读取真实净流量和库存：

- 双层正流量：35 秒。
- 三层物质稳态：60 秒。

条件失效时进度缓慢回退，没有清零。玩家会看到错误合成和焦点迁移造成的影响，也有修复机会。

### 接触准备

准备选择把前期构筑带进敌人阶段：

- 库存玩家获得更低损失上限。
- 产能玩家获得更低脉冲成本。
- 研究玩家获得更长预警和更低样本预算。

它提供法则以外的第二个小决策，并写入 1 点路线信号。

## 需要观察的试玩数据

- 玩家第一次主动点击次数。
- 玩家是否注意到长期目标、下一解锁与成长 / 干预页角标。
- 玩家是否能在不滚动页面的情况下发现画布信标，并理解悬浮层不会暂停任务。
- 首个天赋的分配时间与四项选择率。
- 三种主动观测的使用时机、平均存满时长与未使用比例。
- 第二个夸克生产单元购买时间。
- 核子生产单元购买前的等待时间。
- 双层正流量任务回退次数与累计回退秒数。
- 原子研究时各层库存、生产单元和 RP/s。
- 原子工业阶段因合成造成的核子最低库存。
- 物质稳态任务回退原因：焦点、核子库存、原子库存、净流量。
- 接触准备的选择率、完成时间和中断次数。
- 玩家是否提前建立接触。
- 三种敌人方法的完成时间和实际损失。
- 总完成时间、主动操作次数和最长无操作区间。

## 后续候选

主动观测已经承担基础等待期操作。下一阶段仍可在原子研究后加入 2–3 个低频短项目，每轮只出现一个：

- 局部衰变：临时降低某层生产，玩家选择迁移焦点或消耗库存校准。
- 研究偏差：两个研究样本给出不同加速与路线记录。
- 轨道拥塞：生产单元过多时出现短时需求峰值，允许停机、保护或承担损失。
- 余量交换：用一层库存换取另一层的临时产能。

短项目在玩家已经理解流量图后出现，持续 45–90 秒，不占用第一轮核心教学名额。候选权重继续读取隐藏路线系数并使用反向补偿。
