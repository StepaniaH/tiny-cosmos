# Tiny Cosmos 玩法方向

状态：总体设计稿；二十分钟“第一次接触”竖切已实现
更新日期：2026-07-18

文档索引见 `docs/game-design/README.md`。

## 当前问题

现有版本已经具备完整数值循环：点击获得夸克、购买生产者、向高层合成、积累研究点、解锁文明、执行大坍缩、分配恒定点。

主要问题集中在决策密度：

| 操作 | 当前情况 | 需要补充的内容 |
| --- | --- | --- |
| 点击夸克 | 开局有效，很快失去作用 | 转为少量主动机会和现象处理 |
| 购买生产者 | 大多遵循买得起就买 | 资源保护、限速和局部专精 |
| 合成 | 只需要判断能否支付 | 普通、过载、保留库存等处理方法 |
| 研究 | 固定顺序解锁下一层 | 法则、实验和当前层改造 |
| 代谢 | 玩家只能查看扣除 | 焦点、保护线、暂停和交换 |
| 大坍缩 | 提供恒定点并重开 | 结局、继承物和下一轮规则变化 |

新层级目前主要改变名称、颜色和倍率。两次宇宙之间的操作顺序接近，玩家很少需要回顾自己此前做过的选择。

## 预期体验

玩家管理一条会短缺、过载和受到反宇宙干扰的资源链。每轮通过数十个小决策形成发展倾向，最后得到一个与整局过程对应的结局和继承物。

主动操作频率保持在几十秒到数分钟一次。离线和放置继续产生基础进度；主动玩家通过准备、判断和规则组合提高效率。

## 周目结构

1. 选择一件主继承物。
2. 继承物改变本轮事件、法则和敌人处理方法。
3. 玩家发展七层资源，并处理短项目、现象和敌人。
4. 系统记录推进、维持、求证、改写四类倾向。
5. 文明根据整局历史提出终局方案。
6. 完成终局后执行定向大坍缩。
7. 从两件候选中选择新的继承物，进入下一轮。

普通大坍缩始终可用，提供恒定点和安全重开。定向大坍缩额外生成结局记录和继承物。

完整规则见 `docs/game-design/loop-and-inheritance.md`。

## 局内控制

### 宇宙焦点

玩家把一个焦点放在已解锁层级，获得该层的局部效果。效果可以由法则改变：

- 提高生产。
- 提高研究贡献。
- 降低相邻代谢。
- 观测敌人和异常。

焦点移动具有短暂承诺期，避免购买和合成前后反复切换。

### 储备保护

玩家为重要层级设置保护线。高层代谢和部分敌人截流会尊重保护线。强力事件可以暂时突破保护线，界面需要提前说明。

保护线提供三个用途：

- 防止资源链完全停摆。
- 支持短项目和稳态目标。
- 让玩家明确选择哪些层级优先存活。

### 资源状态

每层显示短缺、循环、过载三种状态，并列出主要流入和流出。玩家通过状态判断焦点和保护线，无需阅读多个精确小数。

## 小决策

重要选择来自当前状态：

- 低层短缺时关闭高层、透支产出、记录样本。
- 资源过剩时储存、过载合成、开放交换。
- 敌人出现时压倒、断供、观测、同步。
- 新研究出现时强化生产、代谢、观测或法则交替。
- 文明形成后分配工程、缓冲、档案和同步资源。

每个选项说明立即影响、持续时间、主要后续和路线标记。玩家能查看近期哪些决定推动了当前终局提案。

## 伪随机选项池

系统按照阶段、资源压力、敌人状态、继承物和近期选择生成候选。

连续偏向某一方向时，其他方向的选项权重逐步提高。该规则增加变化，也给玩家提供转向机会。专精路线仍有稳定来源：继承物、主动实验和保底选项。

关键规则：

- 当前候选写入存档，重新载入不会刷新。
- 教学、路线校准和终局必要事件固定出现。
- 每组三选一包含当前倾向、补偿方向和情境选项。
- 玩家选择后，系统按预告执行结果。
- 离线期间事件进入队列，不会过期。

完整权重和保底规则见 `docs/game-design/decision-pool.md`。

## 反宇宙

反宇宙由熵痕、未采用法则和被排除状态形成。敌人直接影响现有经济：

- 截取新增产出。
- 暂时占用生产能力。
- 提高局部代谢。
- 干扰研究和实验。
- 改变法则的副作用。

损失具有预警和上限。被截取的资源进入可见敌人核心，处理后可以取回、研究、交换或做成载荷。

第一只敌人采用真空水蛭：

- 压倒：短时交付大量资源。
- 断供：保护库存并切断目标层供给。
- 观测：允许有限截流，换取完整样本。
- 同步：让敌人核心与当前资源进入特定变化区间。

四种处理分别推动四类结局。详细规则见 `docs/game-design/adversarial-system.md`。

## 四个结局

### 越过视界

整局多次采用过载、集中投入和快速突破。文明建造视界引擎，通过数个公开窗口完成点火。结局记录玩家带走了什么，也记录原宇宙和镜像文明被留下的部分。

### 无尽花园

整局重视保护、恢复和资源交换。文明建造双生生态圈，在数轮扰动中保持可恢复循环。结局记录谁承担缓冲、双方拥有多少控制权。

### 最后观测者

整局保留样本、预测敌人并完成反事实实验。文明建造最后观测站，补齐起源、结构和意图证据。结局记录知识由谁保管、观测核是否继续干预。

### 双生大坍缩

玩家已经完成多个公开结局，并在本轮使用相反策略完成同步实验。文明建造熵之钟，让正面和背面同时坍缩。下一轮携带一组有明确约束的矛盾规则。

结局形成、提案和继承物见 `docs/game-design/victory-routes.md`。

## 细枝玩法

首批候选：

- 一个短项目槽，提供两到五分钟目标。
- 宇宙现象队列，保留一到两个待处理事件。
- 第一次结局后解锁两个自动化规则槽。

后续候选：

- 三层资源共振。
- 生命谱系。
- 文明派别委托。
- 宇宙档案和动态称号。
- 回归报告。
- 继承物刻印。

详细范围见 `docs/game-design/side-branches.md`。

## 从 Cookie Clicker 可参考的部分

- 开局操作很快得到反馈。
- 短期购买、中期目标和长期收藏同时存在。
- 系统按进度逐步出现。
- 偶发机会让回到页面的玩家有事可做。
- 重置会打开新内容。
- 文案和名称能记录一轮游戏的个性。

Tiny Cosmos 会使用宇宙现象、继承物、敌人核心、档案和多结局承接这些功能。

## 验证标准

- 第一处有后果的选择在开局十分钟内出现。
- 前三十分钟长时间空窗需要有清楚的待完成目标。
- 主动收益来自判断和准备，高频点击不形成数量级优势。
- 每个公开结局可以通过至少两组不同决策记录形成。
- 玩家能指出本轮结局由哪些选择推动。
- 反向补偿增加选项变化，仍能连续专精。
- 敌人损失具有预警、上限和恢复方法。
- 继承物改变下一轮前十分钟。
- 普通大坍缩一直可用。

## 平台方向

首个完整循环继续使用网页版本，桌面浏览器优先。两个公开结局和多轮继承稳定后，再评估 Steam 封装样片。详见 `docs/architecture/platform-direction.md`。
