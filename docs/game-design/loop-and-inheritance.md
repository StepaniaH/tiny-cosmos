# 周目循环、结局形成与继承物

状态：设计稿
更新日期：2026-07-18

## 本文处理的问题

当前大坍缩主要提供恒定点。第二轮速度更快，操作过程变化有限。多结局加入后，如果结局只负责播放不同文本，重玩动力仍然不足。

新的周目结构由六个环节组成：

1. 开局装备一件继承物。
2. 继承物改变本轮可出现的事件、实验和规则。
3. 玩家在生产、研究、敌人和现象中持续做小决策。
4. 系统记录四类路线倾向和若干具体事件。
5. 文明根据整局历史提出终局方案。
6. 定向大坍缩产出新的继承物，下一轮获得新的选项组合。

循环重点放在规则变化和内容变化。恒定点继续承担基础提速，继承物负责改变玩法。

## 四类路线倾向

系统内部记录四个数值，界面仅显示大致状态和已发生的重要事件。

| 内部倾向 | 常见行为 | 对应结局 |
| --- | --- | --- |
| 推进 | 过载、集中投入、快速合成、主动承担熵压 | 越过视界 |
| 维持 | 保护库存、限制高层、恢复赤字、建立交换 | 无尽花园 |
| 求证 | 观测敌人、保留样本、验证预测、接受有限损失 | 最后观测者 |
| 改写 | 交替采用相反策略、同步双方状态、保留矛盾法则 | 双生大坍缩 |

倾向只表示这局做过什么，不直接充当消费货币。

### 倾向来源

每个重要选项带有一组内部标记。例如：

| 决策 | 内部记录示例 |
| --- | --- |
| 对真空水蛭过载注入 | 推进 +2，改写 +1 |
| 关闭高层生产，恢复低层库存 | 维持 +2 |
| 允许水蛭完成一次受控截流 | 求证 +2，维持 +1 |
| 在两种相反法则间完成一次完整周期 | 改写 +2，求证 +1 |
| 把敌人核心转为一次爆发 | 推进 +2，求证 -1 |
| 把敌人核心接入资源回流 | 维持 +2，改写 +1 |

内部数值仅用于选项生成、终局提案和结局变体。玩家会看到“远征倾向明显”“花园路线正在形成”等描述，也能查看造成该判断的最近几项事件。

### 行为记录

部分倾向来自持续行为，无需弹出选择框：

- 三层资源连续维持正净产出。
- 在高熵状态下完成一次研究突破。
- 预测敌人目标并提前调整焦点。
- 先制造赤字，再在规定时间内恢复。
- 让正面和背面资源变化进入同步区间。

系统只在首次或关键里程碑时记录，防止玩家重复刷同一动作。

## 小决策如何形成结局

文明阶段以前不要求玩家选定路线。系统根据整局历史生成终局提案。

### 提案生成

文明诞生时执行以下步骤：

1. 计算四类倾向的强弱和必要事件是否完成。
2. 倾向最高且满足基础条件的路线成为主提案。
3. 倾向第二高的公开路线成为备选提案。
4. 玩家可完成一次校准项目，换入另一条公开路线。
5. 双生大坍缩满足解锁条件时，可能占用隐藏提案位置。

主提案带有整局形成的优势。备选提案可以完成，准备时间会稍长。校准项目提供转向机会，通常需要三到五分钟的针对性操作。

### 终局确认的作用

选择终局工程会固定最后阶段的目标，整局历史仍然决定以下内容：

- 工程从哪个阶段开始。
- 镜像文明采取什么态度。
- 哪些应对方式已经解锁。
- 终局中的资源压力分布。
- 结局变体和可获得的继承物候选。

玩家在终局只做最后一次确认。结局的主要内容已经由此前的小决策写成。

### 四个结局的形成条件

#### 越过视界

基础条件：

- 推进倾向处于前两位。
- 完成过一次受控爆发或过载合成。
- 文明仍保有可用于载荷的生命或档案。

结局变体取决于：玩家保留的载荷、是否击破敌人核心、多少资源留给原宇宙。

#### 无尽花园

基础条件：

- 维持倾向处于前两位。
- 完成过一次赤字恢复或多层稳态。
- 与反宇宙发生过一次可控交换或安全隔离。

结局变体取决于：谁承担缓冲、允许多大波动、镜像文明是否获得对等控制权。

#### 最后观测者

基础条件：

- 求证倾向处于前两位。
- 至少保留一份完整敌人样本。
- 完成一次预测或反事实实验。

结局变体取决于：证据是否共享、观测核是否退出、文明是否建立分布式观测。

#### 双生大坍缩

基础条件：

- 已经获得至少两种公开结局的真理。
- 本轮完成过两组方向相反的关键决策。
- 改写倾向达到要求。
- 正面与背面状态完成一次同步实验。

结局变体取决于本轮携带的两种真理、最终保留的矛盾法则和双方各自牺牲的能力。

## 继承物规则

### 获取

每次定向大坍缩生成两件继承物候选，玩家选择一件加入收藏。候选由结局路线和本轮具体行为共同决定。

例子：同样完成越过视界，携带生命种子的玩家容易获得“边疆种舱”，携带档案的玩家容易获得“折叠档案匣”。

普通大坍缩提供恒定点，不生成路线继承物。

### 装备

- 每轮开局装备一件主继承物。
- 完成数个结局后可解锁一个记忆槽，只能装备效果较小的记录类物品。
- 未装备的继承物保留在收藏中，不提供被动倍率。
- 开局确认后，主继承物在本轮无法随时更换。

装备限制能控制数值膨胀，也能让每轮开局形成清楚的计划。

### 成长

重复完成同一路线不会无限叠加产量。已有继承物会出现一次分支刻印：

- 强化其原有规则。
- 增加一种新用法和一项新约束。
- 分化成适合另一条路线的混合版本。

每件继承物设置有限刻印层数。达到上限后，再次完成相同结局会提供其他继承物或收藏内容。

### 继承物影响范围

一件合格的继承物至少改变以下一项：

- 选项池中会出现什么事件。
- 某种小决策增加新的处理方法。
- 一个资源层级拥有新的用途。
- 敌人初始关系或行为顺序发生变化。
- 某个终局工程出现新的变体。

单纯提供固定产量加成的继承物只适合少量基础物品。

## 四类继承物样例

### 越过视界继承物

#### 裂界火种

- 每轮可储存一次焦点爆发。
- 使用后提高本轮熵压，反宇宙事件更早出现。
- 选项池增加“提前透支”和“边界测试”。

#### 边疆种舱

- 可以把一种低层资源封存为文明载荷。
- 封存期间该资源无法使用。
- 完成花园结局时可演化为“迁徙种荚”。

#### 折叠档案匣

- 开局保留一条已完成实验的提示。
- 本轮第一条法则选择中，观测类选项出现概率增加。
- 适合从远征转向观测的周目。

### 无尽花园继承物

#### 共生种荚

- 一层资源首次跌破保护线时触发缓冲回流。
- 高库存会更容易吸引截流型敌人。
- 选项池增加交换和生态实验。

#### 季候环

- 玩家可以提前查看下一次资源扰动的大致方向。
- 每轮必须经历一次幅度较小的季候变化。
- 连续选择推进选项后，季候变化会提前。

#### 迁徙种荚

- 来源于边疆种舱与花园结局的混合刻印。
- 允许保护目标在两个层级间迁移。
- 迁移期间两层生产都暂时下降。

### 最后观测者继承物

#### 因果透镜

- 每个阶段可查看一个选项的内部倾向标签。
- 使用后，被查看选项的结果幅度略有波动。
- 选项池增加预测和反事实事件。

#### 噪声档案

- 保留一种敌人的部分行为记录。
- 敌人会出现一个新的变体，旧答案不能完全复用。
- 重复观测可以把它刻印为跨敌人通用的“模式索引”。

#### 共同署名

- 镜像文明更早发送可解读信号。
- 部分事件要求同时考虑双方收益。
- 完成远征结局时可生成“双生使节”载荷。

### 双生大坍缩继承物

#### 双相摆

- 每个阶段可将一个已出现选项替换一次。
- 替换结果优先来自当前倾向较弱的方向。
- 使用次数有限，不能持续重抽。

#### 矛盾种子

- 开局选择两条交替生效的轻量规则。
- 规则切换周期公开显示。
- 相关实验要求玩家利用切换，无法长期停在有利一侧。

#### 共同触发器

- 第一次反宇宙接触可以选择合作同步。
- 合作会跳过常规战利品，并推进隐藏路线条件。
- 镜像文明若长期受到攻击，会关闭该选项。

## 一次三轮循环示例

### 第一轮

玩家多次选择过载、快速合成和敌人压倒，最终完成越过视界。载荷选择生命种子，获得“边疆种舱”。

### 第二轮

边疆种舱使远征类事件更容易出现。系统检测到推进倾向持续偏高，提高稳态、保护和交换选项的出现权重。玩家开始保护低层，并把一次敌人核心接入回流。文明提出越过视界与无尽花园两个方案。玩家完成无尽花园，“边疆种舱”获得混合刻印，变成“迁徙种荚”。

### 第三轮

迁徙种荚支持移动保护线。玩家在季候变化中多次预测资源缺口，又完整观测一次镜像信号。求证倾向逐渐上升，最后观测者成为主提案。结局产出“因果透镜”。

三轮使用同一套资源系统，选项、敌人关系和终局条件逐轮变化。

## 数值和内容控制

- 主继承物只装备一件。
- 固定倍率加成设置较低上限。
- 路线专属事件同时带来机会和约束。
- 反向选项补偿会在连续偏向时逐步增加，仍保留玩家继续专精的路径。
- 结局首次完成奖励内容，重复完成奖励刻印和变体。
- 收藏完成度不直接乘算生产倍率。

## 验证问题

1. 玩家能否解释本轮结局由哪些小决策形成？
2. 装备继承物后，前十分钟是否出现可辨认的新操作？
3. 同一结局的不同过程能否产出不同继承物候选？
4. 连续走同一路线是否仍然出现需要重新考虑的选项？
5. 混合刻印是否提供新玩法，还是把两件物品效果简单相加？
6. 普通大坍缩是否保留了可靠的退出途径？
