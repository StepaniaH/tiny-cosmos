# Tiny Cosmos 世界观圣经与名词表

状态：Build 0.5 规范基线
更新日期：2026-07-18
用途：统一游戏界面、剧情、设计文档和后续资产中的世界观口径。若其他讨论稿与本文冲突，以本文和已实现机制为准。

## 一句话前提

玩家是一枚能跨越大坍缩保留微弱记录的观测核。它管理一次由七个尺度构成的微型宇宙；每当它确定一种法则或结果，未被采用的可能性就会在视界背面获得密度，最终形成会反过来影响当前宇宙的结构。

游戏持续追问：

> 当一次宇宙只能实现部分可能性时，那些没有被选择的可能性去了哪里？

## 已确定的世界规则

### 玩家是观测核

观测核不是神、文明领袖或传统意义上的人工智能助手。它是历次大坍缩之间仍能保留少量观测与偏转能力的装置，也是玩家在界面中的行动身份。

观测核可以：

- 把有限注意集中到一个物质尺度。
- 为一层资源公开设置不可轻易突破的库存底线。
- 根据已经取得的长期记录确定局部法则。
- 保存路线记录、宇宙真理和继承物。

观测核不能：

- 无中生有地创造高层结构。
- 取消所有熵、损失和选择代价。
- 替尚未出现的生命与文明决定一切。
- 把背面宇宙简单判定为需要消灭的错误。

界面编号 `TC-07` 是当前观测节点编号，不表示这是第七次宇宙，也不提前规定观测核共有多少枚。

### 七层是管理尺度

夸克、核子、原子、分子、细胞、生命和文明是玩家能够管理的七个尺度。它们服务于玩法可读性，不宣称完整模拟现实宇宙学、粒子物理或生命演化。

高层由低层合成，也会持续消耗相邻低层。低层不是已经过时的初级货币；任何高层繁荣都需要一条仍在运行的底层资源链。

### 观测会排除可能性

焦点、法则和关键决策让当前宇宙从多个可能状态中获得一个可重复结果。被排除的状态不会彻底消失，它们与高吞吐产生的熵痕一起退到观测视界背面。

“观测者效应”在游戏中是世界规则与玩法法则，不等同于对现实量子力学的严格陈述。

### 背面宇宙不是天然邪恶

背面宇宙由三类内容形成：

1. 当前宇宙未采用的法则可能性。
2. 高吞吐、不稳定演化和失败操作留下的熵痕。
3. 观测核为固定结果而排除的其他状态。

它不是现实物理中的反物质、暗物质或严格定义的平行宇宙。第一次接触时，它只能形成噪声和截流结构；生命出现后，它会模仿组织；文明出现后，它也可能形成能够解释自身处境的镜像文明。

从背面视角看，当前宇宙的每一次确定都可能是另一侧的匮乏。因此敌人可以被压倒、隔离、理解或同步，但不会被统一写成纯粹恶意。

### 损失会在另一侧获得形状

真空水蛭截取的资源不会简单储存在一个传统战利品箱里。截取关系会在视界边缘形成核心余像。玩家处置余像，是在决定这次损失今后以燃料、循环或证据的形式留在当前宇宙。

这个规则解释了敌人为什么直接作用于既有经济，也解释了处理敌人为什么会形成路线信号。

### 路线不是阵营或道德分

推进、维持、求证和改写只记录玩家实际采用过的方法：

| 信号 | 常见行为 | 未来公开路线 |
| --- | --- | --- |
| 推进 | 集中投入、爆发、压倒、承担短期熵压 | 越过视界 |
| 维持 | 保护、恢复、限速、建立循环 | 无尽花园 |
| 求证 | 观测、保留样本、预测、公开证据 | 最后观测者 |
| 改写 | 交替相反策略、保留矛盾、同步双方 | 双生大坍缩 |

主信号代表当前证据最支持哪种方法，备选信号代表另一条已经证明可行的方向。直到文明正式提交终局工程，玩家都没有被固定为某个阵营。

## 第一次接触的完整剧情链

### 序幕：坍缩后的核

上一轮宇宙已经失去可读结构。观测核冷启动，只保住了识别“噪声是否回应注视”的能力。玩家通过五次点击建立最初响应，再让生产单元接管重复。

这一段只建立好奇与控制感，不出现惩罚。

### 第一幕：可以持续的物质

夸克被合成成核子。玩家第一次看见即时合成与长期流量的差别，并使用宇宙焦点承认一个限制：观测核无法同时看清所有尺度。

双层正流量成立后，资源不再只是库存，也成为可以复查的长期记录。

### 第二幕：可以描述的结构

研究通道把稳定资源转写成规律，原子层随之被揭示。原子让短暂碰撞第一次成为可以长期辨认的结构。玩家设置储备保护线，并证明三层资源链能维持稳态。

这一步为第一法则提供证据。法则不是技能商店中的任意购买，而是对已经使用过的焦点、保护或研究系统作出优先解释。

### 第三幕：退到背面的描述

第一法则确定后，未采用的法则与此前熵痕在视界背面形成第二组影子。玩家能提前读取目标、速率和损失上限，并选择一项接触准备。

真空水蛭是这组影子第一次获得的稳定形状。它被命名为“水蛭”只是因为行为类似附着与截取，并不证明它是生物。

### 第四幕：双方都留下记录

玩家可以：

- 用过载脉冲压碎核心。
- 保护低层、隔离原子供给，让附着失去来源。
- 主动扩大受控损失预算，记录完整截取样本。

第一次接触不会开放同步。同步需要跨周目样本和矛盾法则，确保它是理解双方之后的玩法，而不是首轮万能选项。

真空水蛭退去后，核心余像被转成边界燃料、循环回流或行为档案。系统据此生成主路线信号、备选信号和本轮接触报告。

这份报告不是结局。它是未来生命、文明与镜像文明引用的第一份关系证据。

## 文案声音

界面信息分为三个层次：

- `SYS / CTRL / TACTIC`：确定、简洁、先说明机制。
- `OBS / LAW / ARCHIVE`：观测核的解释，可以有克制的诗意。
- 生命与文明通信：拥有立场，会引用玩家此前的具体行为。

任何诗意句子都不能替代操作信息。敌人界面必须同时公开目标、速率、上限、条件与失败恢复。

## 暂不确定、不得提前写死的内容

- 观测核由谁制造、共有多少枚。
- 背面宇宙是否在第一轮开始前就已经存在某种主体。
- 镜像文明最终是统一声音还是多个派别。
- 四种终局中哪一种更接近“正确答案”。
- TC-07 编号是否与未来元叙事有关。

这些内容可以作为线索，但在正式定稿前不得由普通系统日志直接宣布答案。
