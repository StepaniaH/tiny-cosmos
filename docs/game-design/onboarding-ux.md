# 前二十分钟引导与交互反馈

状态：已实现第一版
更新日期：2026-07-18

## 目标

前二十分钟需要解决三个问题：

1. 玩家能找到当前可操作的位置。
2. 玩家能理解操作对资源链产生的直接影响。
3. 世界观信息跟随操作出现，不要求玩家先阅读长篇背景。

界面保留自由操作。引导遮罩不会锁住其他按钮。玩家收起浮层时，浮层会缩向顶部任务条；任务条右端随后显示“打开引导”。

每项基础教学结束后安排 20—40 秒自由观测。此时不会引入新术语，也不会打开下一项系统，玩家可以继续刚学会的操作。顶部任务条显示下一项指令的剩余时间，观测指令面板说明当前适合积累或检查的数值。

## 两层引导

### 顶部任务条

顶部任务条承担持续信息：

- 当前为第几项指令。
- 整个竖切的完成位置。
- 当前指令的名称。
- 当前指令的实时完成进度。

进度读取游戏状态，重新载入后不会回退。涉及两个条件的任务会同时显示两项，例如“累计原子 12/18 · 生产单元 1/2”。稳定观测显示连续有效秒数，条件失效时进度以每秒 0.5 秒的速度回退。

### 场景引导浮层

浮层承担当下解释：

- 聚光框标记需要操作的控件。
- 四块半透明遮罩降低其他区域亮度。
- 背景段说明当前世界发生了什么。
- 操作段给出控件位置、次数、成本和预期结果。
- 底部小进度条与顶部任务条使用同一状态。

目标位于屏幕外时，页面会把该控件滚动到可见区域。手机布局下，浮层固定在屏幕底部，减少遮挡目标按钮。

## 宇宙焦点的说明

宇宙焦点当前遵循以下规则：

- 同时只能聚焦一个资源层。
- 基础生产倍率为 1.8 倍。
- 急剧膨胀法则会把焦点倍率提高到 2.25 倍。
- 局部守恒与保护线叠加时，界面显示叠加后的实际倍率。
- 迁移焦点不消耗资源。
- 观测真空水蛭需要把焦点放在原子层。
- 断供方案要求焦点离开原子层。

核子教学先要求玩家建立一个核子生产单元，再开放聚焦操作。玩家可以从三个位置核对结果：核子卡片的倍率标签、中央画布左上角的焦点状态、右下角流量监视器的核子产出柱。

开局不预设焦点。玩家完成核子生产教学后第一次建立焦点，界面此前只显示“焦点未建立”。这样不会在教学前提前获得隐藏的 1.8 倍产出。

聚焦和保护按钮提供悬浮说明。键盘聚焦按钮时也会显示同一说明。

## 物质流量监视器

中央画布原有的资源数字框已经移除。新的监视器位于画布右下角，初始保持最小化，在焦点教学开始后自动展开一次。

展开状态显示每个已研究资源层的三根柱：

- 绿色：每秒产出。
- 红色：每秒消耗。
- 青色：每秒净流量。
- 琥珀色净流量：该层正在减少。
- 紫色横线：研究通道当前总增长速度。

各柱按当前可见资源中的最大物质速率归一化。紫线采用独立的右侧对数轴，范围为 0.005—1 RP/s，刻度为 0.01、0.1、1。物质流量和研究速率不共用单位；图内明确标注“研究速率·对数右轴”，并显示精确 RP/s。研究公式、各层贡献和总倍率在研究构成面板中展开。玩家可以随时最小化监视器，只保留标题条。

## 操作反馈

当前已加入以下轻量反馈：

- 点击中央光核产生画布粒子，并在操作位置显示“夸克 +1”。
- 合成后显示新资源数量。
- 购买生产单元时资源卡片闪亮一次。
- 迁移焦点时资源卡片闪亮，并显示实际用途。
- 研究新层时显示高优先级系统提示。
- 指令切换时顶部任务条闪亮，并显示新指令名称。
- 法则、接触方案和余像处置会显示“已记录”。

动效只改变反馈，不改变结算时机。系统遵循操作后立即结算、立即更新数值的顺序。系统设置为“减少动态效果”时，CSS 会缩短全部动画。

## 美术资产需求

当前二十分钟版本可以继续使用 Canvas 与 CSS 几何图形。模型与图标有固定占位，缺失资产不会中断流程。

如果开始制作专用资产，优先级如下：

1. 观测核中心：待机、点击响应、研究解锁三个状态。
2. 真空水蛭：形成、附着、退去三个状态。
3. 三项第一法则图标。
4. 四类路线信号图标。
5. 敌人处理与终局工程演出。

二维资产可以直接制作并接入：透明 PNG、SVG、序列帧、WebM 动效都适合现有页面。当前电脑已经安装 FFmpeg，可以处理序列帧、压缩和透明视频转换。

三维资产使用 GLB：

- 观测核控制在 2–6 万三角面。
- 真空水蛭控制在 4–8 万三角面。
- 单个模型尽量保持 1–2 套材质。
- 纹理使用 1024 或 2048 分辨率。
- 动画名称保持 `idle`、`pulse`、`attach`、`retreat` 这类短英文标识。

当前电脑已检测到 Blender 5.2.0 LTS。资产暂不直接接入页面；先按清单批量制作并验收，再选择 Three.js 或轻量 GLB 查看器。完整文档入口见 [`docs/art/README.md`](../art/README.md)，给 Cursor 的总任务书见 [`docs/art/AI-ASSET-HANDBOOK.md`](../art/AI-ASSET-HANDBOOK.md)，运行时入口见 [`assets/manifest.json`](../../assets/manifest.json)。
