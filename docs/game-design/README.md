## 状态含义

- **canonical**：当前采用的产品、世界观或设计约束。
- **implemented**：准确记录当前版本已经做了什么；若与 canonical 冲突，表示实现待对齐。
- **proposal**：可复用的设计方案，尚未全部确认或实现。
- **historical**：已完成、被取代或仅用于追溯的记录。

### 当前采用的玩法约束

以下约束已经由上位文档确认，即使对应详细规格仍需更新：

- 局内继续围绕资源链、宇宙焦点、储备保护、研究和低频决策。
- 前四轮使用推进、维持、求证、改写四类方法；它们改变过程和局部后果，不取消终结。
- 反侧结构继续直接作用于现有经济，不新增传统战斗系统。
- 主动玩法来自判断、准备、短项目、证据和建设，不来自高频点击。
- 离线和忽略可选事件不应造成不可恢复损失。
- 天赋、继承物和跨轮成长优先解锁新规则与新选项，固定倍率设上限。
- 操作层中文必须具体清楚，诗意文案不能替代条件、成本和失败恢复。

## 文档之间的职责边界

- 产品愿景回答“为什么做、最终让玩家感受什么”。
- 世界观圣经回答“世界实际是什么、玩家何时能知道”。
- 五轮主叙事回答“每轮怎样揭示、怎样失败和怎样留下钩子”。
- 玩法规格回答“玩家操作什么、系统如何反馈”。
- implemented 文档回答“当前版本实际做到哪里”。
- 平衡文档回答“数值循环能否稳定运行”。
- 生产记录回答“哪些资产已经完成并接入”。

同一条当前结论只在一个上位文档维护，其余文件使用链接引用，避免再次出现多个互相冲突的“当前建议工作顺序”。

## 当前叙事对齐提示

在旧文档中看到以下说法时，使用新口径解释：

| 旧说法 | 当前口径 |
| --- | --- |
| 玩家是一枚跨轮观测核 | 玩家是当前宇宙；TC-07 是内部自观测功能，身份在第五轮揭示 |
| 背面宇宙由未采用法则形成 | 这是前期模型；另一侧实际是另一个宇宙 |
| 四个胜利结局 | 四种局部成立的终末方案，最终都无法取消终结 |
| 双生大坍缩是隐藏路线 | 改写方法之一，不是真结局 |
| 第四轮共同署名后进入更高轮次 | 第四轮合作仍失败，第五轮进入档案总结 |
| 宇宙真理是正确答案 | 有适用条件、可被修正的跨轮结论 |
