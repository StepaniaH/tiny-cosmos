# 第二轮可玩竖切：答案的反例

状态：12 节点可玩框架与全套重生资产已实现，等待完整人工平衡  
更新日期：2026-07-23  
工作章名：**回声有了方向 / The Echo Chose a Direction**

## 体验目标

第二轮不重复“从不会操作到学会七层资源”的第一轮节奏。玩家已经理解点击、生产、合成、研究、焦点和保护线，因此本轮从一条能够自动运行的夸克—核子链开始，把注意力放到四个新问题：

1. 上一轮究竟留下了什么，而不是只获得了多少倍率。
2. 旧答案怎样让新宇宙产生可测量的初始偏差。
3. 反宇宙怎样根据上一轮成功方法设计针对性反例。
4. 第二座文明是否接受第一座文明的证词，以及第一条真理是否需要修正。

建议首次完成时间为 24–32 分钟。前 90 秒必须让玩家看懂“真理、继承物、反例、长期目标”，但不重新解释基础按钮。

## 四条路线的反例不是换皮

### 推进：闭界格栅

- 上轮证明：视界能够被打开。
- 反侧学习：在高吞吐出现前预测出口并关闭方向。
- 公开条件：焦点位于原子层、核子库存至少 8、核子净流量不为负。
- 设计问题：远行是否把代价留给没有同行的结构。
- 操作差异：玩家必须一边暴露自己的高层方向，一边保住低层余量，不能只冲刺产量。

### 维持：逆季候

- 上轮证明：对立可以形成闭合循环。
- 反侧学习：把正面盈余翻译成反侧短缺季。
- 公开条件：核子保护线公开、夸克与核子都有盈余、至少保留 6 原子。
- 设计问题：稳定由谁承担冬天，缓冲是否公开。
- 操作差异：同时经营两层净流量与一层样本，不允许用隐藏低层亏空伪造稳态。

### 求证：盲区证人

- 上轮证明：证词能够比终结活得更久。
- 反侧学习：只在没有被聚焦的层级行动。
- 公开条件：焦点离开原子、盲区保留 8 原子、至少保留 24 RP。
- 设计问题：证据是否只有在持续凝视下才成立。
- 操作差异：主动放弃最直接的观测加成，在盲区中保留可复查样本。

### 改写：失同步摆

- 上轮证明：矛盾规则可以共同运行。
- 反侧学习：保留一个永远不同步的拍点。
- 公开条件：焦点迁移至少 3 次、保留 6 核子和 8 原子。
- 设计问题：同步是允许差异，还是消除差异。
- 操作差异：必须迁移焦点并保持两套库存，不能长期停在最有利的一侧。

## 碎片化叙事布置

碎片不会暂停资源系统，不提供必须点击才能继续的假选择。它们按当前任务停留时间触发，并使用固定存档种子，重新载入不能刷新。

| 碎片 | 触发节点 | 作用 | 与第一轮关联 |
| --- | --- | --- | --- |
| 先于物质的校验和 | R2-BIAS-01 约 8 秒 | 说明继承的是“抵达结构的偏好” | 读取 `priorLaw` |
| 尚未出生者的引文 | R2-ATOM-01 约 14 秒 | 文明语言早于本轮生命出现 | 读取 `civilizationWitness` |
| 另一侧的预演 | R2-PROOF-01 约 11 秒 | 对方预测方法而非具体按钮 | 读取 `dominantRoute` 与反例 |
| 被继承的空位 | R2-LIFE-01 约 18 秒 | 未建成未来在谱系中成为缺口 | 读取 `abandoned` |

强制剧情决策与偶发碎片分开：强制决策进入“干预”工作区的决策队列，偶发碎片先在画布显示“新发现”信标，点击后进入悬浮阅读层。悬浮层不会暂停生产或正在进行的稳态计时。

## 继承校准

开场不是选择一件完全不同的装备，而是决定如何运行已经随坍缩抵达的主继承物：

- **沿用偏差**：保留完整路线加速，并接受反侧更早识别旧方法。
- **设置阻尼**：把主偏差压到一半，让上轮备选路线更有修正空间。
- **公开代价**：保留偏差，额外提高研究速率，并把它限制的未来写入档案。

这三项不是善恶或难度选项。它们分别强调重复检验、修正检验和版本公开。

## 第二座文明与真理裁定

第二座文明不会再次生成“主提案 / 备选提案”的第一轮结算。它需要评价一条已经存在的真理：

- **重复证明**：`truthRepeated = true`，保留本轮公开的适用条件。
- **修正后成立**：`truthRevised = true`，把备选路线和反例结果写入真理定义。
- **保留争议**：两项布尔值均为 `false`，异议作为第三轮输入继续存在。

文明证词另有独立结果：

- `accept`：有条件接受祖先证词。
- `challenge`：保留原文，同时给予反驳同等档案级别。
- `defer`：证据不足，暂缓采用。

真理裁定和证词回应分开，避免“同意祖先”自动等于“重复原路线”。

## 存档与状态

第一轮文明完成后，界面提供“让主提案穿过大坍缩”。执行后：

1. 生成结构化 `LoopSignature`。
2. 把签名加入 `state.loop.signatures[]`。
3. `state.loop.number` 变为 2。
4. 重置本轮资源、研究和任务状态。
5. 保留恒定点、累计夸克、里程碑和跨轮签名。
6. 应用第二轮双层起点并播放七幕重生序列。

第二轮专属状态位于 `state.slice.roundTwo`：

```text
inheritanceMode
biasProgress
fragmentChoice
counterexample { id, status, choice }
proofProgress
witnessResponse
truthVerdict
truthRepeated
truthRevised
```

存档版本为 slice v7。旧版第一轮存档会补齐 `state.loop` 和 `roundTwo` 默认值，不会被误判成第二轮。

## 信息预算

第二轮第一屏只显示三层资源视界，其中夸克与核子可操作、原子作为下一层目标。研究、决策队列和路线信号从开场可见；反宇宙接触面板在反例节点才出现。

决策队列使用新的层级：

```text
继承校准 → 证词碎片 → 路线反例 → 后来者异议 → 真理裁定
```

路线面板顶部单独显示“继承路线”，下面的四条路线计量只记录第二轮真实选择，避免把上轮结果自动算成本轮立场。
