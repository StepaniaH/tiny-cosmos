## 共同约束

- 四条路线复用资源链、宇宙焦点、储备保护、实验、法则和反宇宙。
- 四条路线共享同一资源链，终局目标、操作顺序和风险结构各不相同。
- 前期小决策持续形成推进、维持、求证、改写四类倾向；文明阶段生成主提案和备选提案。
- 终局确认只锁定最后阶段，提案优势、镜像态度、结局变体和继承物候选继续读取整局记录。
- 普通大坍缩始终是安全出口，不能因为终局工程造成硬锁。
- 四个结局处理同一个世界观问题，没有统一的价值排序。
- 定向大坍缩生成两件继承物候选，下一轮装备一件主继承物。
- 文档中的时长、阈值与倍率均为待验证假设。
