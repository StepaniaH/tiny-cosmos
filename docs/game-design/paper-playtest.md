# 小决策、多结局与继承物纸面试玩

状态：可执行草案
更新日期：2026-07-18

## 试玩目的

纸面试玩先验证四件事：

1. 玩家能否根据当前资源和敌人状态做出选择。
2. 文明阶段提出的结局能否对应玩家记得住的整局行为。
3. 反向补偿能否增加转向机会，同时保留继续专精的选择。
4. 结局继承物能否让下一轮出现新的操作和问题。

本方案压缩生产等待和数值增长，只测试决策关系。一次单轮测试约三十分钟；三轮继承测试约九十分钟。

## 参与者

- 一名主持人：维护隐藏倾向、事件权重、敌人规则和资源变化。
- 一名玩家：只查看公开资源状态、事件选项、近期路线记录和结果预告。
- 可选记录员：记录玩家的选择理由、犹豫点和规则误解。

主持人不能在选择前解释哪项会导向哪个结局。玩家提出机制问题时，只回答选项已经公开的立即效果、持续时间和风险上限。

## 材料

### 公开材料

- 七张资源层卡：夸克、核子、原子、分子、细胞、生命、文明。
- 每层三个状态标记：短缺、循环、过载。
- 一个宇宙焦点标记。
- 三个保护线标记，后续阶段可增加到四个。
- 一个当前项目槽。
- 一个活动队列，最多保留两个事件。
- 一张真空水蛭卡，标出目标、截流上限和核心进度。
- 四张终局工程卡。
- 十二张继承物卡，每条路线三张。

### 主持人材料

- 推进、维持、求证、改写四条隐藏倾向记录。
- 四条路线的必要事件勾选表。
- 每个方向的选项供给差，取值零到四。
- 最近两次事件和处理方法标签。
- 一枚固定随机种子。纸面测试可使用预先写好的抽取序列代替随机数。
- 每张事件卡的基础权重、出现条件、路线标记和后续卡编号。

## 压缩资源规则

每个阶段只处理资源状态，不计算大数：

- **短缺**：本阶段无法支付一个普通项目；连续两阶段短缺会让上一层也进入短缺。
- **循环**：可以支付一个普通项目，阶段结束后状态保持。
- **过载**：可以支付一个高成本项目；若没有处理，下一阶段增加一次熵压事件。

每轮开始时，夸克和核子处于循环，其余层级随阶段逐步解锁。玩家每个决策点可以移动一次焦点，焦点把一层状态向上改善一级。保护线可以阻止一次由代谢或敌人造成的状态下降。

这些规则只用于加快纸面测试。正式原型仍使用连续资源数量和净产出。

## 隐藏记录规则

### 单次选择

- 主要方向增加 2 点。
- 明确包含第二种处理方式时，相关方向增加 1 点。
- 纯资源奖励不增加倾向。
- 同一张事件卡用同一处理方法重复出现时，只记录第一次。

### 持续行为

以下行为首次完成时增加 1 点：

- 在过载状态完成一次研究：推进。
- 连续两个决策点没有短缺层：维持。
- 根据敌人预告提前移动焦点并命中目标：求证。
- 让相反法则或双方状态完成一次完整交替：改写。

### 必要事件

倾向领先仍需满足路线基础条件：

- 越过视界：至少一次受控爆发。
- 无尽花园：至少一次短缺恢复或多层循环。
- 最后观测者：至少一份完整敌人样本。
- 双生大坍缩：持有两种公开真理，并完成一次同步实验。

## 事件生成流程

每个决策点按以下顺序生成：

1. 找出由当前短缺、过载、研究、敌人或文明状态触发的事件主题。
2. 移除当前无法支付、前置条件不满足和处于冷却的处理方法。
3. 为有效处理方法计算路线补偿、供给差、继承物和重复修正。
4. 放入一个与当前主倾向相容的选项。
5. 放入一个倾向较弱且权重最高的补偿选项。
6. 放入一个直接处理当前资源或敌人问题的情境选项。
7. 三项发生重复时，按权重从剩余方法补位。

玩家看见候选后，对应方向的供给差归零；没有进入候选的方向供给差加一。玩家选择后才更新路线倾向。

## 第一轮固定剧本

第一轮用于检查公开三结局的形成。同步处理只作为锁定线索出现。

| 决策点 | 公开局面 | 可能出现的处理方法 | 后续检查 |
| --- | --- | --- | --- |
| 一：第一法则 | 原子刚进入循环 | 急剧膨胀、局部守恒、观测者效应 | 法则是否改变后两张卡的选项 |
| 二：低层缺口 | 核子短缺，分子项目待启动 | 暂停高层、预支下一阶段产出、保留缺口作为样本 | 玩家是否理解立即代价 |
| 三：真空水蛭 | 敌人将在两个决策点内截流原子 | 过载压倒、保护线断供、设定预算观测 | 玩家是否根据准备选择处理方法 |
| 四：核心结算 | 敌人核心留下被截资源 | 制成边界燃料、接入资源回流、封存为行为样本 | 敌人处理是否产生后续用途 |
| 五：细胞项目 | 高层推进与低层恢复争夺同一资源 | 快速涌现、三层稳态、反事实一分钟 | 是否出现路线转向 |
| 六：宇宙现象 | 一次脉冲可接入当前系统 | 立即点火、分散为缓冲、记录运动轨迹 | 细枝事件能否影响主循环 |
| 七：文明分配 | 只能优先完成两项准备 | 边界载荷、生态种子库、因果档案 | 玩家是否记得此前形成的方向 |
| 八：文明提案 | 系统展示主提案和备选提案 | 接受主提案、接受备选、进行校准 | 提案是否符合玩家预期 |

第三到第七个决策点使用加权候选，主持人无需把表中全部方法同时给玩家。

## 文明提案结算

主持人按顺序执行：

1. 检查三条公开路线的必要事件。
2. 在满足条件的路线中按倾向排序。
3. 第一名成为主提案，第二名成为备选提案。
4. 第一名缺少必要事件时，显示缺失条件，并让下一名满足条件的路线成为主提案。
5. 玩家可以接受提案，或执行一张固定校准卡换入第三条公开路线。

界面模拟卡需要展示：

- 形成提案的三项最近记录。
- 终局已有优势。
- 还需完成的步骤。
- 主要风险和失败回退位置。
- 可能出现的继承物类型。

主持人在玩家确认后询问：“你认为哪些选择让这个提案出现？”记录玩家能否说出至少两项具体事件。

## 压缩终局

纸面测试将每条详案压缩成三个决策：

### 越过视界

1. 决定爆发保留到第二窗口或最终发射。
2. 决定击破敌人核心取回燃料，或保留谈判窗口。
3. 从生命种子、知识档案和镜像样本中选择载荷。

### 无尽花园

1. 从七层中选择四个关键生态层。
2. 决定哪一侧承担第一次短缺缓冲。
3. 选择对等、庇护或野性共生结构。

### 最后观测者

1. 设定低、中、高三档损失预算。
2. 从焦点、储备和法则中选择一个变量进行检验。
3. 选择共同档案、静默退出或自观测宇宙。

### 双生大坍缩

1. 选择有效质量与保留库存。
2. 封存一项本轮优势，换取同步宽限。
3. 选择带入下一轮的矛盾规则组合。

每次终局失败只回退一个决策，并提供一次调整机会。普通大坍缩卡始终放在桌面上。

## 继承物结算

结局完成后，根据路线和最后两个关键选择生成两件候选：

| 结局 | 过程记录 | 候选池偏向 |
| --- | --- | --- |
| 越过视界 | 使用高熵爆发 | 裂界火种 |
| 越过视界 | 携带生命种子 | 边疆种舱 |
| 越过视界 | 携带知识档案 | 折叠档案匣 |
| 无尽花园 | 保护线承担主要缓冲 | 共生种荚 |
| 无尽花园 | 接受多轮扰动 | 季候环 |
| 无尽花园 | 由远征载荷转入 | 迁徙种荚 |
| 最后观测者 | 多次预测目标 | 因果透镜 |
| 最后观测者 | 保留完整行为 | 噪声档案 |
| 最后观测者 | 与镜像共享证据 | 共同署名 |
| 双生大坍缩 | 多次交替处理方法 | 双相摆 |
| 双生大坍缩 | 携带矛盾法则 | 矛盾种子 |
| 双生大坍缩 | 与镜像共同牺牲 | 共同触发器 |

玩家选择一件加入收藏。下一轮开始前从收藏中装备一件主继承物，主持人把继承物增加的事件卡和限制卡放入牌组。

## 三轮继承测试

### 第一轮：建立偏向

- 不携带继承物。
- 使用固定事件序列。
- 目标是让玩家自然完成一个公开结局。
- 记录玩家是否能预测主提案。

### 第二轮：继承物改变开局

- 装备第一轮获得的继承物。
- 前三个决策点至少出现一个继承物专属处理方法。
- 主持人启用反向补偿，增加较弱方向的机会。
- 记录玩家会继续原路线、转向，还是形成混合记录。

### 第三轮：检查重复和隐藏路线

- 玩家从收藏中重新选择主继承物。
- 若已取得两种公开真理，加入同步假说和轮回派委托。
- 检查双生大坍缩是否通过可追溯条件出现。
- 若仍未满足，界面只显示缺少的同步条件，不要求玩家猜隐藏操作。

## 主持人记录表

每个决策点记录：

- 当前资源状态。
- 展示的选项及其方向。
- 玩家选择。
- 玩家选择前说出的理由。
- 立即结果是否符合预期。
- 后续哪张卡引用了该选择。
- 四类隐藏倾向。
- 四类供给差。
- 玩家是否觉得某个结局已经被锁定。

每轮结束再记录：

- 玩家预测的主提案和实际主提案。
- 玩家能复述的关键选择数量。
- 玩家是否考虑过备选或校准。
- 继承物是否让玩家想立即尝试下一轮。
- 哪个决策只是在比较资源数量，没有形成取舍。

## 通过条件

### 单轮形成

- 至少三分之二的测试者能说出主提案来自哪两到三项选择。
- 同一固定开局可以通过不同选择形成至少两个公开结局。
- 备选提案具有完成空间，玩家不会因前两个选择判断本轮已经报废。

### 伪随机补偿

- 连续选择同一方向后，两个决策点内至少出现一次有效转向机会。
- 想继续专精的玩家仍能在每个重要事件中找到一个可行方法。
- 补偿选项与当前局面有关，不会为了凑方向出现无关事件。

### 继承循环

- 继承物在下一轮前三个决策点内产生一次新操作或新约束。
- 第二轮的关键选项序列与第一轮有明显差异。
- 玩家选择继承物时会考虑玩法变化，固定产量大小不会成为唯一标准。

### 四个结局

- 四条终局都使用资源、焦点、保护、敌人和法则中的既有操作。
- 每条终局至少包含准备、变化应对和最终表达三个决策。
- 结局文本能引用本轮的载荷、缓冲、证据或共同牺牲。
- 双生大坍缩的出现条件可以从档案和缺失提示中追溯。

## 失败后的修改顺序

1. 玩家看不懂局面：先改公开信息和选项结果说明。
2. 提案与玩家预期不符：检查路线标记和必要事件，再考虑调整权重。
3. 每轮都走同一路线：检查事件供应、反向补偿和继承物限制。
4. 继承物只影响数值：给它增加专属处理方法或新约束。
5. 终局像独立小游戏：删去新货币，让终局重新读取资源链和本轮记录。
6. 试玩时间过长：减少重复事件，保留形成提案所需的关键决策。

每次试玩只改一到两类问题，并保留旧记录用于比较。
