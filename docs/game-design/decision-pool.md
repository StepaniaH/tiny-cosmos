# 小决策与伪随机选项池

状态：设计稿
更新日期：2026-07-18

## 目标

四个结局需要由整局行为积累形成。玩家每隔一段时间遇到一个与当前资源、敌人或实验相关的小问题。选项来自伪随机选项池，系统会参考本轮倾向、资源缺口、近期重复和继承物进行加权。

随机性负责提供变化。选择权和结果说明始终留给玩家。

## 决策频率

建议节奏：

- 开局十分钟：两到三个教学型决策。
- 原子到细胞：每三到六分钟一次重要决策。
- 生命到文明：每五到八分钟一次重要决策。
- 同时只保留一个待处理的重要决策。
- 普通现象可以进入队列，离线期间不失效。

频率需要结合实际首轮时长重新测试。长时间放置期间，系统可以积累一个事件名额，不能堆成十几个弹窗。

## 决策来源

### 资源决策

由库存、净产出和保护线触发。

示例：

- 核子长期过剩：建立临界储仓、转为研究样本、开放给反宇宙交换。
- 原子接近耗尽：关闭高层、透支未来产出、观测短缺过程。
- 三层同时稳定：扩大循环、主动打破稳态、记录稳态样本。

### 研究决策

由新层级、实验完成或异常数据触发。

示例：

- 新法则优先强化生产、代谢、观测或相位切换。
- 把研究点投入下一层、改造现有层、解码敌人信号。
- 保留一个未完成假说，下一轮通过继承物继续研究。

### 敌人决策

由征兆、入侵和敌人退去触发。

示例：

- 过载击破、切断供给、允许受控截流、同步敌人核心。
- 追回资源、保留样本、建立交换膜、把核心做成载荷。
- 公开镜像文明信号、封存、误导或共同验证。

### 文明决策

由生命和文明阶段触发。

示例：

- 资源优先供给边界工程、生态缓冲、观测站或同步实验。
- 允许某个派别管理一个层级。
- 决定哪些记录公开给镜像文明。
- 决定终局失败时优先保全人口、档案或生产基础。

### 继承物决策

由装备的主继承物触发，每轮数量有限。

示例：

- 裂界火种：立即释放、继续蓄积、拆成生态缓冲。
- 共生种荚：保护当前层、迁移到高层、开放一次镜像交换。
- 因果透镜：查看选项标签、扫描敌人意图、保留到文明阶段。

## 选项数据结构

每个选项在设计表中至少包含：

- 所属阶段。
- 出现条件。
- 基础权重。
- 四类倾向变化。
- 立即资源影响。
- 延迟影响。
- 可触发的后续事件。
- 与哪些继承物、法则、敌人状态相容。
- 最近出现后的冷却轮数。
- 玩家可见的结果预告。

结局关键条件和教学事件使用固定触发，不交给随机权重决定。

## 隐藏系数

系统维护以下内部状态：

| 系数 | 用途 |
| --- | --- |
| 路线倾向 | 记录玩家本轮选择方向 |
| 选项供给差 | 记录某类选项多久没有出现 |
| 最近重复 | 降低连续出现相似内容的概率 |
| 资源压力 | 提高与当前短缺、过剩相关的事件权重 |
| 敌人压力 | 决定对抗事件的频率和强度范围 |
| 继承偏向 | 增加继承物相关事件和处理方法 |
| 阶段系数 | 限制某些内容只在合适层级出现 |
| 剧情冷却 | 防止连续弹出多段叙事事件 |

系数随存档保存。重新载入页面不会重新抽取当前选项。

## 权重调整规则

可使用下面的结构理解权重，具体数字在原型阶段确定：

`最终权重 = 基础权重 × 阶段修正 × 情境修正 × 继承修正 × 反向补偿 × 重复惩罚`

实际生成分两步进行：

1. 先按资源、研究、敌人和文明状态选择一个事件主题，例如“原子短缺”或“真空水蛭即将附着”。
2. 再从该事件可用的处理方法中组成两到三个选项，确保每项都能在当前资源状态下执行。

事件主题主要读取情境系数，处理方法主要读取路线倾向、继承物和反向补偿。这样可以避免“系统为了平衡路线，给原子短缺的玩家弹出一件无关文明事件”。

### 反向补偿

玩家连续选择同一方向后，相关路线已经得到充分表达。系统逐步提高其他方向的选项权重。

例子：

- 连续三次选择推进，维持和求证选项更常出现。
- 长期维持稳态，系统增加爆发机会、外部扰动和未知样本。
- 多次观测敌人，系统增加需要立即决断的资源危机。
- 多次改写规则，系统增加要求固定承诺的项目。

反向补偿只改变可见机会。系统不会替玩家选择，也不会在选定后暗改结果。

### 专精保留

平衡机制需要保留继续专精的途径：

- 每组选项至少包含一个与当前主倾向相容的处理方法，条件允许时执行。
- 继承物能够保证少量路线专属事件出现。
- 玩家可以主动启动路线实验，减少等待随机选项的时间。
- 文明主提案仍然优先参考实际选择，不根据平衡权重强制换路线。

### 保底规则

- 某类公开路线选项连续四次未进入候选，下次权重显著提高。
- 玩家达到路线校准条件后，校准项目固定出现。
- 敌人首次教学、第一次法则和终局必要事件固定出现。
- 每组三选一避免出现三个同方向选项。
- 资源无法承担某个选项的最低代价时，该选项不进入候选。
- 离线回归事件不会要求玩家立即支付大额资源。

### 纸面试玩初始参数

以下数字用于第一轮纸面测试，不能直接视为最终平衡值：

| 项目 | 初始规则 |
| --- | --- |
| 主要路线记录 | 一次关键选择增加 2 点 |
| 次要路线记录 | 同一选择可以给相关方向增加 1 点 |
| 持续行为记录 | 首次达到里程碑增加 1 点，同条件重复不再增加 |
| 倾向差补偿 | 某方向每落后最高倾向 1 点，处理方法权重增加 10%，最多增加 80% |
| 供给差补偿 | 某方向连续一次未进入候选，下一次权重增加 20%，最多累计四次 |
| 重复惩罚 | 同标签连续出现一次乘 0.6，连续出现两次乘 0.35 |
| 继承物修正 | 直接相关处理方法乘 1.4；每个事件最多应用一次 |
| 权重边界 | 所有修正后限制在基础权重的 0.25 到 3 倍 |

候选展示后，该方向的供给差归零，无论玩家是否选择。路线倾向只读取玩家实际选择和完成的行为，看到某个选项不会影响结局。

这套初始值需要重点观察两种情况：

- 补偿方向是否在玩家需要时出现，且没有连续占满候选。
- 玩家连续选择同一路线时，相关选项能否依靠主倾向槽、继承物和主动项目持续获得。

若补偿过强，先降低倾向差上限；若候选长期重复，先提高供给差和重复惩罚。不要同时调整多个系数，否则纸面记录难以判断原因。

## 每次提供几个选项

默认使用三个：

1. 一个与当前主要倾向相容。
2. 一个来自补偿方向。
3. 一个紧贴当前资源或敌人状态。

部分事件只需要两个清楚选项。四个以上会增加阅读量，适合文明议案和继承物选择等低频节点。

选项文本同时显示：

- 立即影响。
- 会持续多久。
- 可能推动的后续方向。
- 是否会产生熵压、敌意或样本。

具体隐藏数值无需展示。玩家可以在观测日志中查看选择留下的路线标记。

## 伪随机示例

当前状态：玩家装备裂界火种，最近连续选择两次推进，原子库存偏低，真空水蛭即将出现。

假设当前倾向为推进 8、维持 2、求证 3、改写 1。按纸面参数，维持与求证获得倾向差补偿；推进处理受到近期重复惩罚，同时从裂界火种获得继承修正。事件主题仍锁定为“原子短缺与水蛭征兆”，不会因为补偿切换到无关主题。

候选池可能生成：

### 选项一：提前点火

- 消耗裂界火种，立刻补充原子。
- 提高熵压。
- 记录推进倾向。

### 选项二：关闭分子生产

- 暂停分子生产一段时间。
- 恢复原子保护库存。
- 记录维持倾向。

### 选项三：保留缺口

- 允许原子短缺持续到水蛭出现。
- 损失受保护线上限约束。
- 获得一次短缺与敌人目标关系的样本。
- 记录求证倾向。

裂界火种提高了选项一的基础机会。连续推进触发反向补偿，选项二和选项三进入候选。最终决定仍由玩家做出。

## 防止读档刷选项

- 每轮使用固定随机种子。
- 当前候选生成后立即写入存档。
- 关闭页面再打开仍显示同一组候选。
- 放弃一个事件会产生明确冷却或轻量代价。
- 调试模式可以固定事件序列，便于平衡验证。

## 结局与选项池的关系

终局提案使用玩家已选内容计算。系统不能用“曾经出现但玩家没选”的选项影响结局。

继承物会改变下一轮选项供应：

- 增加一组路线相关事件。
- 为通用事件增加一个处理方法。
- 提高某类法则进入候选的权重。
- 同时提高反向补偿速度，防止连续周目完全重复。

## 内容制作规范

每个新事件先回答四个问题：

1. 它由什么当前状态触发？
2. 三个处理方法会改变哪些操作？
3. 结果会在本轮哪个时点再次出现？
4. 它会如何影响结局或继承物？

只提供资源奖励、没有后续影响的事件控制在少数。连续阅读量控制在几行内，背景内容放入可展开日志。

## 验证标准

- 同一种构筑连续三轮不会遇到完全相同的关键选项序列。
- 反向补偿能增加其他方向机会，玩家仍能继续专精。
- 玩家知道每个选项的近期代价和主要方向。
- 读档无法刷新候选。
- 随机选项不会阻断公开结局。
- 事件频率不会打断放置节奏。
- 选择结果会在后续资源、敌人、终局或继承物中留下可见影响。
