# Event audio notice

The event sounds in `sfx/` were generated for Tiny Cosmos from deterministic MIDI compositions using FluidSynth and the Vintage Dreams Waves v2.0 SoundFont.

- SoundFont author: Ian Wilson (1996; updated 1998)
- Upstream license record: <https://github.com/FluidSynth/fluidsynth/blob/master/sf2/COPYRIGHT.txt>
- Rendered assets contain no copied third-party sample files or personal metadata.
- The SoundFont itself is not distributed in this repository.

Only short, on-demand MP3 event sounds are included in the web build. Long-form music stems and 3D/VFX production assets remain outside the runtime package.
