## Prompt set

Every candidate uses the shared style prompt and frame 03 specification in
[`docs/art/prologue-storyboard-prompts.md`](../../../docs/art/prologue-storyboard-prompts.md).
The candidate-specific prompt deltas were:

- **A — engineering-readable:** slightly low three-quarter view, maximal
  mechanical legibility, one active cyan node. The model introduced a pedestal,
  so this candidate does not satisfy the floating-apparatus invariant.
- **B — floating orthographic:** near-orthographic view, no support structure,
  six-axis layout emphasized. The node housings drifted toward camera lenses.
- **C — graphic-novel instrument:** matte blackened alloy, subtle ink contours,
  six identical low-profile faceted pods, no lenses, calm oblique view. **Locked
  by product review on 2026-07-22 as the canonical Observer Core master.**
- **D — cinematic silhouette:** darker, simpler and more illustrated, with the
  smallest emissive area. The central core reads more like a dark mineral shell
  and the six-node count is less immediate.

All prompts repeated these hard constraints: exactly three mutually
perpendicular complete rings, exactly six total nodes, exactly one active node,
five dark nodes, no text or pseudo-text, no vehicle/weapon/magic imagery, left
42% and bottom-left 34% reserved for subtitles, and a recognizable mobile crop.
